# Proposal

## Why

知识库详情页的版面在三轮实测后暴露四个结构问题：

1. 知识库顶部有一条横跨整个知识库区的搜索带，纸面只能从它下方开始，正文起点被推到约 140px，顶部留白过多。
2. 文档条把「文件名 / 保存时间 / 五个动作 / 格式工具栏」压在一条 flex 里，两行信息没有分割线，11px 的保存时间与 14px 的文件名共基线，视觉上偏下。
3. 大纲开关会改变正文列宽：开启后第一列少 188px，正文块整体平移约 94px；宽敞档在较窄面板下还会被 `min()` 挤窄，行内字数变少。
4. 新建与打开目录的入口散落三处（知识库顶栏文字按钮、树头图标、文档条文字按钮），顶栏那两个与树头语义重复。

## What Changes

1. **搜索框移入左列顶部**：占用树列宽度（168 + 232），高 28px；知识库区不再有横跨整栏的顶带，左列不再显示「知识库 / 全部条目」标题行。
2. **纸面顶行拆两行**：第一行左侧文件名（衬线）+ 保存时间（基线对齐），右侧五个纯图标动作（排版 / 复制 / 大纲 / 贴到桌面 / 删除）；第一行与第二行之间加细分割线；第二行为格式工具栏，独占整行并与正文左缘对齐；工具栏下缘保留 1px 朱砂收口线。
3. **大纲轨道常驻 188px**（176 栏 + 12 间距）：开关只控显隐，不参与布局计算；正文列宽与水平位置不随大纲开关变化（**取代** `kb-doc-shell` 7.1 的「从留白里让出」）。
4. **正文上移**：纸面从窗口顶端 12px 起，正文起点由约 140px 降到 112px。
5. **入口收敛**：删除知识库顶栏的「打开数据目录」与「+ 新建」；树头右侧为「打开数据目录」图标与「额外操作」图标，后者点开菜单包含「新建文件夹」「新建文件」两项，复用既有右键菜单组件与既有创建命令。
6. **底部留白沿用** `clamp(64px, 14vh, 160px)`，不再另设。
7. **存量冲突修正**：`kb-doc-shell` 的 7.1 与其规格条款（大纲占正文右侧留白）被本变更取代。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `knowledge-base/workspace`：顶部只保留搜索；树头承载打开目录与额外操作；条目动作收敛到树头菜单。
- `knowledge-base/doc-shell`：文档条两行结构、分割线与基线、正文起点上移。
- `knowledge-base/outline`：大纲轨道常驻，开关不移动正文。

## Impact

- 代码：`src-react/src/views/KbView.tsx`、`src-react/src/components/kb/kb-tree.tsx`、`src-react/src/components/kb/kb-item-detail.tsx`、`src-react/src/views/kb.css`。
- 文档：`docs/capability/06-知识库.md`。
- 无新依赖、无新 Tauri 命令、不触命令 parity 门禁。
- 归档顺序：`kb-writing-experience` → `kb-doc-shell` → 本变更（三个 change 都改同一组能力，倒序归档会覆盖前者的条款）。
