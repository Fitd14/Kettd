# sticky-shell-polish · L4 真机验收清单

本机（WebView2 dev 沙箱，无 GUI）做不了 `tasks.md` 里剩下的 7 项，这份清单把它们变成可以照着点、照着记的步骤。
步骤里的类名、文案、热键都取自当前源码，改动其中任何一个都要同步改这里。

执行前统一准备：

- 一台能跑 GUI 的 Windows，`npm run dev`（构建在另一台机器，见 design.md Migration Plan 的「构建机器约定」）。
- 数据目录指向临时目录，别写生产数据：`$env:KETTD_DATA_DIR = "$env:TEMP\kettd-l4-<日期>"`。
- 记下两个版本号，后面 4.3 要填：WebView2 = `(Get-ItemProperty 'HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}').pv`；系统 = `Get-ComputerInfo | Select WindowsProductName,OsBuildNumber`。
- 每项末尾的「记录」一行照抄到交付报告的「验证证据」段；失败项贴现象 + 复现步骤。
