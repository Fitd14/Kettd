# Spec Delta

## MODIFIED Requirements

### Requirement: 阅读字号仅限编辑器正文

阅读面字号 SHALL 在 `12–24px` 之间逐像素取档（共 13 档，默认 15px），由用户在文档工具条的排版弹层里决定；该档 MUST NOT 出现在 chrome 元素（页面标题、按钮、列表行、空态）上。知识库详情标题 SHALL 与该档同档，标题层级 MUST 按既有倍率随之等比缩放。阅读主题 MAY 提供正文行高系数、H1–H6 倍率、标题字距与标题底线，未提供时 MUST 沿用默认值（编辑器行高 1.85、只读渲染 1.65，倍率 1.35 / 1.2 / 1.05 / 1 / .93 / .88 与 1.5 / 1.3 / 1.15 / 1.05 / .98 / .92）；主题 MAY 另改引用、代码、表格、链接与图片的装饰，并 MAY 覆盖外壳配色令牌（背景、卡片、弹层、主色、次级色、静音色、边框、输入、聚焦环、链接、印章色），但 MUST NOT 改变字号档位本身（含 chrome 四档），也 MUST NOT 改变正文字距（标题字距与用户档位叠加），MUST NOT 改 `--font-ui` / `--font-serif` 与语义色。

#### Scenario: 正文与 chrome 并存

- **WHEN** 知识库详情同时显示标题、标签与编辑器正文
- **THEN** 标题与正文同档，标签仍为 chrome 的 11 / 12.5 档，两层行高互不干扰

#### Scenario: 未设置时的默认档

- **WHEN** 用户从未调整过阅读字号
- **THEN** 正文与标题均为 15px，行高 1.85，比本次变更前（16px）略紧凑、每行多容纳约一个字

#### Scenario: 逐像素调档

- **WHEN** 用户在排版弹层里把阅读字号从 15px 调到 16px
- **THEN** 正文与标题立即变为 16px，H1–H6 按 `1.35 / 1.2 / 1.05 / 1 / .93 / .88` 倍率等比变化，侧栏、列表行、按钮字号不变

#### Scenario: 越界值被拒

- **WHEN** 设置里出现 `12–24` 之外的数值（如 11px 或 30px）
- **THEN** 系统回退到 15px 并正常显示正文，界面不出现异常字号

#### Scenario: 便签窗不受影响

- **WHEN** 用户把知识库阅读字号设为 24px 后打开知识便签
- **THEN** 便签正文仍为 16px，便签标题不放大

#### Scenario: 主题提供标题倍率

- **WHEN** 已选主题声明 H2 倍率为 1.3，阅读字号为 18px
- **THEN** H2 渲染为 23.4px，正文仍为 18px；切回默认主题后 H2 回到 1.2 倍

#### Scenario: 主题换外壳配色但不动字号与字族契约

- **WHEN** 已选主题把背景、卡片与边框换成暖纸色，同时把代码块底色改为 `#ECECEE`、表格加斑马纹、纸面圆角设为 16px
- **THEN** 页面背景、卡片、按钮底色随之换装，但 chrome 字号四档（11 / 12.5 / 14 / 22px）、`--font-ui` 与按钮文字层级不变；危险按钮与优先级色仍为系统语义色

### Requirement: 阅读面字族可由用户切换

知识库正文使用的 `--font-reading` SHALL 由 `settings.readingFont` 决定，取值 MUST 限定为三态：空串（跟随 `--font-ui`）、`system:<族名>`（本机已装字体）、`file:<文件名>`（用户上传，存于数据目录 `fonts/`）；切换 MUST 只影响阅读面，MUST NOT 改变 `--font-ui` 与 `--font-serif`。当 `readingFont` 为空串且用户已选阅读主题时，`--font-reading` SHALL 取该主题声明的字族；用户显式选择的 `system:` / `file:` MUST 优先于主题字族。

#### Scenario: 默认无设置
- **WHEN** `readingFont` 为空串
- **THEN** 不输出 `--font-reading` 覆写，正文回落 `var(--font-ui)`，与全站一致

#### Scenario: 选择系统字族
- **WHEN** 用户在设置页选「楷体」
- **THEN** `readingFont` 落库为 `system:KaiTi`，编辑器正文显示为楷体，页面标题、按钮、列表行仍是黑体

#### Scenario: 上传自己的字体
- **WHEN** 用户选择本机一个 `.ttf`（≤16 MB）
- **THEN** 文件被复制进 `<数据目录>/fonts/`，以 `FontFace` 注册为 `Kettd Reading` 并立即生效；重启应用后仍生效

#### Scenario: 字体不可用时不吞正文
- **WHEN** 记录里的字体文件已被删除或损坏
- **THEN** 正文静默回落到 `var(--font-ui)`，MUST NOT 出现空白或错误页

#### Scenario: 主题字族在未选字体时生效
- **WHEN** `readingFont` 为空串，用户选中一个声明了「霞鹜文楷」字族的主题
- **THEN** 阅读区正文以该字族渲染，标题与正文同族，页面其余部分仍为 `--font-ui`

#### Scenario: 用户字体压过主题
- **WHEN** 用户已选 `file:文楷.ttf`，随后切换到一个声明了其他字族的主题
- **THEN** 正文仍使用用户上传的字体，主题只改颜色与其他属性
