# Spec Delta

## ADDED Requirements

### Requirement: 文档工具条横贯整栏并固定在滚动区之外

知识库详情页 SHALL 在正文之上渲染一条文档工具条，工具条宽度 MUST 与详情纸面同宽（不得缩进到正文列内），且 MUST 位于正文滚动区之外——正文滚动时工具条不移动、不被正文覆盖，滚动条只出现在正文区（从工具条下缘开始）。工具条 SHALL 分两行：第一行左端显示文件名（就地改名）与保存时间、右端放文档动作，第二行 MUST 由格式工具栏独占整行；两行之间 MUST NOT 混排。

#### Scenario: 宽窗下拉宽工具条

- **WHEN** 主窗口宽度大于 1440px 并打开任意条目
- **THEN** 工具条的左右边缘与详情纸面边缘对齐，第一行是文件名、保存时间与右侧动作，第二行是格式工具栏，正文列仍居中且不再包含工具栏

#### Scenario: 两行不混排

- **WHEN** 用户在任意窗口宽度下打开条目
- **THEN** 格式工具栏的按钮全部落在第二行，MUST NOT 出现在文件名或文档动作那一行

#### Scenario: 长文滚动时工具条不离开视野

- **WHEN** 用户把一篇长文向下滚动超过一屏
- **THEN** 工具条与文件名、保存时间仍在原位，正文从工具条下缘的滚动区里滚过，滚动条只出现在该滚动区

#### Scenario: 左端不空着

- **WHEN** 打开任一已有标题的条目
- **THEN** 工具条左侧显示该条目的标题与「已保存 HH:mm」，标题可点击就地修改，回车或失焦保存

### Requirement: 工具条上的文档动作

文档工具条 SHALL 提供三个文档级动作：排版入口、复制 Markdown、大纲开合；三者 MUST 位于工具条右侧、与格式工具之间以分隔线分开，且 MUST 有可读的中文名称或 `aria-label`。复制动作的图标 MUST 取「文件 + 代码」语义的图形，MUST NOT 使用通用剪贴板图形。

#### Scenario: 窄窗下三个动作仍可用

- **WHEN** 详情面板宽度不足以并排大纲
- **THEN** 排版与复制仍然可点击，大纲按钮改为打开右侧抽屉（见 `knowledge-base/outline`），任何动作都不因窄窗被隐藏

### Requirement: 复制文档为 Markdown

工具条的复制动作 SHALL 把当前条目的 Markdown 原文写入系统剪贴板，成功时 MUST 在按钮上给出不超过 2 秒的可见反馈；剪贴板 API 不可用时 MUST 回退到隐藏文本域 + `execCommand('copy')`，回退也失败时 MUST NOT 报告成功。

#### Scenario: 复制成功

- **WHEN** 用户点击复制按钮且剪贴板可用
- **THEN** 剪贴板内容为该条目保存时的 Markdown 文本，按钮短暂显示「已复制」后复原

#### Scenario: 剪贴板被拒

- **WHEN** `navigator.clipboard.writeText` 抛错
- **THEN** 应用改用隐藏文本域复制，且仅在回退成功时显示「已复制」

### Requirement: 排版入口在文档内

字号、字距、列宽三个档位的控件 SHALL 只出现在文档工具条的排版弹层里，设置页 MUST NOT 再重复提供同一组控件；改动 MUST 先应用到当前文档（即时预览），再合并写回全局设置。

#### Scenario: 在文档里改字号

- **WHEN** 用户打开排版弹层并把字号滑块从 15px 拖到 16px
- **THEN** 正文立即按 16px 重排，松手约 220ms 后设置被写回，其他条目下次打开时沿用同一档位

#### Scenario: 设置页不再重复

- **WHEN** 用户打开设置页的「阅读字体」区块
- **THEN** 只看到字族选择与字体上传，看不到字号 / 字距 / 列宽控件，并有一行文字指出它们已移到文档工具条

### Requirement: 正文底部留白

正文滚动区底部 SHALL 保留一块 64px–160px 的空白（取视口高的 14%，下限 64px、上限 160px），使末行可以滚到视口中部以上、光标不贴屏幕下缘；该留白 MUST NOT 随窗口变高无限增大，MUST NOT 与锚点滚动余量重复叠加。

#### Scenario: 滚到文末

- **WHEN** 用户把光标移到文档最后一行并继续向下滚动
- **THEN** 末行上方仍有一块可观的空白，最后一行停在视口中部附近的舒适位置
