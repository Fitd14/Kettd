# Spec Delta

## REMOVED Requirements

### Requirement: 标题与工具栏对齐正文

**Reason**: 工具栏已从正文列中取出，成为横贯整栏、位于标题之上的文档工具条；「工具栏与正文左缘对齐、不得满宽」与现行布局相反。

**Migration**: 工具栏的行为改由 `knowledge-base/doc-shell` 的「文档工具条横贯整栏并吸顶」约束；对齐要求只保留给标题与正文，见下方新增的「标题与正文对齐、工具条横贯整栏」。

## MODIFIED Requirements

### Requirement: 居中正文列与留白下限

知识库写作区 SHALL 把标题、标签与正文放入同一列并水平居中；正文列宽 MUST 取「面板可用宽与页边栏占位之差」与「用户所选上限」中的较小值，上限 MUST 为两档之一（舒适 96ch / 宽敞 112ch，默认舒适），正文列两侧留白 MUST 不小于 20px。

#### Scenario: 宽窗口居中

- **WHEN** 用户未改动列宽档位，主窗口宽度为 1440px 以上并打开任意条目
- **THEN** 正文列在扣除工具条与页边栏后的可用宽度内水平居中，列宽为该可用宽与 96ch 中的较小值

#### Scenario: 切到宽敞档

- **WHEN** 主窗口宽度为 1440px 或更大，用户把列宽切到「宽敞」
- **THEN** 列宽上限变为 112ch 且大于舒适档，宽表格等块级元素获得更长的可用行宽

#### Scenario: 大纲显示时的居中

- **WHEN** 详情面板宽度大于 1120px、右侧显示页边大纲
- **THEN** 标题、标签与正文仍在剩余空间内居中对齐，页边栏不覆盖正文，左右留白允许不对称

#### Scenario: 窄窗口保留留白

- **WHEN** 详情面板可用宽小于当前档位上限
- **THEN** 正文列占满可用宽度并保留至少 20px 留白，不出现横向滚动条，两档给出相同结果

## ADDED Requirements

### Requirement: 标题与正文对齐、工具条横贯整栏

标题行、标签行与正文首行 SHALL 共用同一条左缘，标题 MUST NOT 随面板宽度满宽拉伸；文档工具条不受此对齐约束，按 `knowledge-base/doc-shell` 的要求横贯整栏。

#### Scenario: 打开条目左缘对齐

- **WHEN** 用户打开任意知识条目
- **THEN** 标题文本、标签行与正文首行的左缘在同一条垂直线上，而工具条的左缘与纸面边缘对齐、更靠左
