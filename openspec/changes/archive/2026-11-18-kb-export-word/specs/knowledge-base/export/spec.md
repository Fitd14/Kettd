# Spec Delta

## Purpose

让知识库文档离开应用后仍保持结构：把一篇文档导出为 Word（`.docx`），由用户决定写到哪个目录，默认落在系统下载位置。

## ADDED Requirements

### Requirement: 详情页提供单篇导出入口

知识库详情页 SHALL 在工具条提供「导出」入口，且一次只能导出一篇当前打开的文档；未打开文档或正文为空时该入口 MUST 不可用。

#### Scenario: 打开文档后可导出

- **WHEN** 用户打开一篇正文非空的文档
- **THEN** 工具条出现可点的「导出」按钮

#### Scenario: 正文为空时禁用

- **WHEN** 当前文档正文只有空白字符
- **THEN** 「导出」按钮呈禁用态，点击不发起任何导出

#### Scenario: 一次只导出一篇

- **WHEN** 用户在某篇文档上触发导出
- **THEN** 只生成这一篇的 `.docx`，不会顺带导出同目录其他文档

### Requirement: 导出前由用户选择目标位置

导出 SHALL 先弹系统保存对话框，默认文件名为 `<文档标题>.docx`、默认目录为系统下载目录；用户取消对话框时 MUST 不发生任何写盘，也不产生错误提示。

#### Scenario: 默认落在下载目录

- **WHEN** 用户首次触发导出
- **THEN** 保存对话框以系统下载目录为默认目录、以 `<文档标题>.docx` 为默认文件名

#### Scenario: 用户改到别的目录

- **WHEN** 用户在对话框里切到另一个目录并确认
- **THEN** 文件写到该目录，文件名沿用对话框中的值

#### Scenario: 取消不写盘

- **WHEN** 用户在保存对话框中点取消
- **THEN** 不创建任何文件，界面无错误提示

### Requirement: 导出保留文档结构与行内样式

导出的 `.docx` MUST 保留标题层级、段落与换行、行内加粗/斜体/行内代码/链接、有序与无序列表（含嵌套缩进）、引用块、代码块、表格（含表头）与图片；代码块 MUST 使用等宽字体，MUST NOT 承诺语法高亮配色。

#### Scenario: 标题与段落

- **WHEN** 正文含 `#`/`##`/`###` 标题与普通段落
- **THEN** Word 中对应为「标题 1/2/3」样式段落与正文段落，层级与原文一致

#### Scenario: 行内样式

- **WHEN** 段落里有 `**加粗**`、`*斜体*`、`` `代码` `` 与 `[文字](链接)`
- **THEN** 对应文字分别呈加粗、斜体、等宽、可点击超链接，其余文字不受影响

#### Scenario: 列表与引用

- **WHEN** 正文含有序列表、无序列表、嵌套一层的子项与 `>` 引用块
- **THEN** Word 中呈现对应的编号/项目符号与逐级缩进，引用块带左侧竖线与缩进

#### Scenario: 表格

- **WHEN** 正文含带表头的 Markdown 表格
- **THEN** Word 中生成同样行列的表格，首行按表头加粗，单元格文本不丢字

#### Scenario: 代码块

- **WHEN** 正文含围栏代码块
- **THEN** Word 中为等宽字体、保留换行与空格的独立段落块，不套用正文行距

### Requirement: 图片随文档嵌入

正文中的 `assets/<文件名>` 图片 MUST 作为内嵌图片写入 `.docx`，并保持原始宽高比、按页面可用宽度等比缩放；图片文件缺失或读取失败时 MUST 以 alt 文案占位并继续导出，MUST NOT 中断整篇导出。

#### Scenario: 图片正常嵌入

- **WHEN** 正文含一张 `assets/<sha>.<ext>` 图片且文件存在
- **THEN** 导出的 `.docx` 内嵌该图片，显示宽度不超过正文可用宽度且不变形

#### Scenario: 图片缺失

- **WHEN** 正文引用的图片文件已被删除
- **THEN** 该位置以 alt 文案（无 alt 时用 `[图片缺失]`）占位，文档其余部分照常导出并成功落盘

### Requirement: 文件名与失败处理

导出文件名 MUST 去掉 Windows 不允许的字符（`< > : " / \ | ? *`）并把连续空白折叠为一个；目标文件已存在时 MUST 由保存对话框承担覆盖确认；写入失败 MUST 返回中文短句错误、MUST 保持原文件不被截断。

#### Scenario: 标题含非法字符

- **WHEN** 文档标题为 `周报/2026: 第三季度`
- **THEN** 保存对话框的默认文件名不含 `/` 与 `:`，可正常保存

#### Scenario: 覆盖同名文件

- **WHEN** 用户选择一个已存在的 `.docx` 并在系统确认框里同意覆盖
- **THEN** 文件被新内容替换，不出现两个同名文件

#### Scenario: 写入失败

- **WHEN** 目标目录不可写（例如只读盘或权限不足）
- **THEN** 界面提示中文短句错误，目标位置不留下半截文件

### Requirement: 导出不改变知识库数据

导出 MUST 只读：MUST NOT 修改正文、图片资源、条目元数据或备份文件；MUST NOT 依赖网络。

#### Scenario: 导出后数据不变

- **WHEN** 用户导出成功后再打开同一篇文档
- **THEN** 正文、图片与条目更新时间都与导出前一致

#### Scenario: 离线可用

- **WHEN** 机器完全断网
- **THEN** 导出照常完成，不出现网络相关错误
