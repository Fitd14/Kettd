# Spec Delta

## Purpose

定义知识库条目与知识便签共用的 Markdown 编辑器的可观察行为，包括输入反馈、格式命令、链接与图片插入、保存与外部回填，确保内容不会因保存链路而静默改变或丢失。

## ADDED Requirements

### Requirement: 保存过程不打断编辑
编辑器的自动保存与外部数据刷新 SHALL NOT 让知识库视图出现空态占位、整列表重排或覆盖用户正在输入的内容。

#### Scenario: 自动保存后列表保持稳定
- **WHEN** 用户在知识库条目编辑器中输入并停止输入达到自动保存防抖时间
- **THEN** 保存完成后知识库列表不出现「空空如也」等空态占位，列表滚动位置与选中项不变

#### Scenario: 保存回包不覆盖新输入
- **WHEN** 自动保存的请求返回时用户已经继续输入了更多内容
- **THEN** 编辑器保留用户的新输入，不回灌旧内容、不重置光标位置

### Requirement: 输入过程保持流畅
编辑器的每次击键 SHALL 只更新必要范围，不得重建扩展集合、触发整页或整列表重渲染；Markdown 序列化 SHALL 仅在防抖后的保存时机执行。

#### Scenario: 长文档连续输入
- **WHEN** 用户在接近 5000 字的知识条目中连续输入
- **THEN** 每次击键不触发扩展重建与全列表数据重拉，输入无可感知卡顿

### Requirement: Markdown 保存保真
编辑器保存 SHALL 保留用户 Markdown 的语义信息；只允许无语义变化的归一化，且归一化结果在再次保存时保持不变（幂等）。

#### Scenario: 表格对齐信息保留
- **WHEN** 文档包含带对齐标记（`:---`、`:---:`、`---:`）的表格并保存后重新打开
- **THEN** 表格的对齐信息仍然保留

#### Scenario: 图片不会整体丢失
- **WHEN** 文档包含 Markdown 图片语法并保存
- **THEN** 图片节点被保留且可再次编辑，不会在保存后消失

#### Scenario: 有损转换必须提示
- **WHEN** 保存链路无法无损表达某段内容（例如不支持的 HTML、嵌入语法）
- **THEN** 系统在保存前给出明确提示或保留原文，不得静默丢弃

### Requirement: 标题级别可分级设置
编辑器 SHALL 提供分级标题下拉（正文、H1–H4），并支持行首输入 `#` 到 `####` 加空格的输入式标题；编辑器与阅读态 SHALL 有对应字号样式。

#### Scenario: 使用标题下拉
- **WHEN** 用户点击工具栏标题控件
- **THEN** 出现「正文 / H1 / H2 / H3 / H4」下拉，选择后当前段落应用对应级别，控件高亮当前级别

#### Scenario: 输入式标题
- **WHEN** 用户在行首输入 `### `（或 H1/H2/H4 对应标记）
- **THEN** 该行转换为对应级别的标题，编辑态与阅读态都呈现对应字号

### Requirement: 行内格式与链接插入
编辑器 SHALL 支持斜体、删除线等行内格式，并通过居中对话框插入链接，替代浏览器原生输入框。

#### Scenario: 斜体与删除线
- **WHEN** 用户对选区点击斜体或删除线
- **THEN** 选区应用对应行内格式，Markdown 输出为 `*文本*` / `~~文本~~`

#### Scenario: 链接对话框
- **WHEN** 用户点击「插入链接」
- **THEN** 打开居中对话框，预填当前链接，提供确定、取消、移除链接；Enter 确认、Esc 取消；不再出现浏览器 prompt

### Requirement: 截图可粘贴为图片（仅知识库条目）
知识库条目编辑器 SHALL 支持把剪贴板中的截图粘贴为图片节点，并在保存后仍可渲染与再次编辑；便签编辑器 MUST NOT 启用图片插入（便签保持 500 字上限）；插入前 SHOULD 压缩到可接受的体积上限并在超限时提示。

#### Scenario: 粘贴截图
- **WHEN** 用户把截图粘贴到编辑器
- **THEN** 图片经压缩后插入正文并立即可见，保存后重新打开仍能显示

#### Scenario: 体积超限
- **WHEN** 待插入图片压缩后仍超过体积上限
- **THEN** 系统提示体积过大并拒绝插入，不写入数据
