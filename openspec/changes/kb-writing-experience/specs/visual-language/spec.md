# Spec Delta

## MODIFIED Requirements

### Requirement: 阅读字号仅限编辑器正文

阅读面字号 SHALL 从 `8 / 10 / 12 / 14 / 16 / 18 / 20px` 七档中取值（默认 16px），由用户设置决定；该档 MUST NOT 出现在 chrome 元素（页面标题、按钮、列表行、空态）上。知识库详情标题 SHALL 与该档同档，标题层级 MUST 按既有倍率随之等比缩放。

#### Scenario: 正文与 chrome 并存

- **WHEN** 知识库详情同时显示标题、标签与编辑器正文
- **THEN** 标题与正文同档，标签仍为 chrome 的 11 / 12.5 档，两层行高互不干扰

#### Scenario: 未设置时的默认档

- **WHEN** 用户从未调整过阅读字号
- **THEN** 正文与标题均为 16px，行高 1.85，与本次变更前的观感一致

#### Scenario: 切到 18px

- **WHEN** 用户在设置页把阅读字号切到 18px
- **THEN** 正文与标题立即变为 18px，H1–H6 按 `1.35 / 1.2 / 1.05 / 1 / .93 / .88` 倍率等比变化，侧栏、列表行、按钮字号不变

#### Scenario: 越界值被拒

- **WHEN** 设置里出现七档之外的数值（如 15px 或 0）
- **THEN** 系统回退到 16px 并正常显示正文，界面不出现异常字号

#### Scenario: 便签窗不受影响

- **WHEN** 用户把知识库阅读字号设为 20px 后打开知识便签
- **THEN** 便签正文仍为 16px，便签标题不放大

## ADDED Requirements

### Requirement: 阅读字距可调

阅读面字距 SHALL 从 `0 / 0.015em / 0.03em / 0.045em / 0.06em / 0.075em / 0.09em` 七档中取值（默认 0），由用户设置决定；该档 MUST 以 `em` 表达而非常量像素，MUST NOT 改变 chrome 字号与标题自带的字距常量。

#### Scenario: 默认字距

- **WHEN** 用户从未调整过字距
- **THEN** 正文字距为 0，正文观感与本次变更前一致

#### Scenario: 选中间档

- **WHEN** 用户把字距切到 0.045em，正文为 16px
- **THEN** 正文字距约为 0.72px，字与字之间出现可感知但不松散的间隙，标题与列表行不受影响

#### Scenario: 与字号档叠加

- **WHEN** 阅读字号为 20px、字距为 0.09em
- **THEN** 实际字距约为 1.8px，随字号等比放大而不是固定像素

#### Scenario: 不改变列宽

- **WHEN** 用户在任一列宽档位下调大或调小字距
- **THEN** 正文列的像素宽度不变，变的是每行可容纳的字数
