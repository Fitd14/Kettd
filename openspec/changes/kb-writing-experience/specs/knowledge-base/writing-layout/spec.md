# Spec Delta

## MODIFIED Requirements

### Requirement: 居中正文列与留白下限

知识库写作区 SHALL 把标题、标签、工具栏与正文放入同一列并水平居中；正文列宽 MUST 取「面板可用宽」与「用户所选上限」中的较小值，上限 MUST 为两档之一（舒适 96ch / 宽敞 112ch，默认舒适），两侧留白 MUST 不小于 20px。

#### Scenario: 宽窗口居中

- **WHEN** 用户未改动列宽档位，主窗口宽度为 1440px 以上并打开任意条目
- **THEN** 正文列水平居中，两侧留白对称，列宽为可用宽与 96ch 中的较小值

#### Scenario: 切到宽敞档

- **WHEN** 主窗口宽度为 1440px 或更大，用户把列宽切到「宽敞」
- **THEN** 列宽上限变为 112ch 且大于舒适档，宽表格等块级元素获得更长的可用行宽

#### Scenario: 窄窗口保留留白

- **WHEN** 详情面板可用宽小于当前档位上限
- **THEN** 正文列占满可用宽度并保留至少 20px 留白，不出现横向滚动条，两档给出相同结果

### Requirement: 不改变主题与字号层级

布局调整 MUST NOT 改变现有配色 token、界面 chrome 的四档字号与行高（正文 1.85、H1–H6 阶梯）；阅读面的字号与字距由用户档位决定，布局改动 MUST NOT 改动它们。

#### Scenario: 深色主题视觉一致

- **WHEN** 在深色主题下切换列宽档位
- **THEN** 正文颜色、字号、行高与切换前一致，仅列宽与对齐发生变化

#### Scenario: 阅读档位不被布局覆盖

- **WHEN** 用户已把阅读字号设为 18px，随后切换列宽档位
- **THEN** 正文仍为 18px，标题倍率与行高关系不变
