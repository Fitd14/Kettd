# app-shell/shortcuts Specification

## Purpose
定义应用层的「直达知识库」全局快捷键能力：用户可单独配置一个打开主界面并跳转知识库的热键，注册失败可回滚且有中文提示，主界面通过统一的导航事件完成切页，与既有四组热键互斥且向后兼容。

## Requirements

### Requirement: 可配置的直达知识库热键

应用设置 MUST 新增独立的「直达知识库」全局热键项，默认值 MUST 为 `Alt+Shift+K`；用户 MUST 能修改、清空并恢复默认值；旧配置缺少该字段时 MUST 按默认值处理且不报错。

#### Scenario: 默认热键可用

- **WHEN** 用户从未修改过该设置并按下 `Alt+Shift+K`
- **THEN** 主界面被显示（必要时先创建），并切到知识库视图

#### Scenario: 清空热键

- **WHEN** 用户将该热键清空并保存
- **THEN** 系统注销该热键，之后按下不再触发
- **AND** 其余四个热键不受影响

#### Scenario: 旧配置兼容

- **WHEN** 用户从旧版本升级，设置文件里没有该字段
- **THEN** 应用正常启动并使用默认值，不出现设置解析错误

### Requirement: 注册、互斥与失败回滚

启动时系统 MUST 尝试注册该热键；它 MUST 与快速记录、主窗口、新建便签、待办悬浮窗四组热键互斥。注册失败（被其他程序占用、系统拒绝、组合非法）时 MUST 保留旧绑定可用、给出中文提示，且 MUST NOT 阻塞应用启动。

#### Scenario: 与其他热键冲突

- **WHEN** 用户把直达知识库热键设置为已有其他功能占用的组合
- **THEN** 保存被拒绝并提示该组合已被其他功能占用
- **AND** 原有热键保持可用

#### Scenario: 被系统占用

- **WHEN** 目标组合已被其他程序注册
- **THEN** 应用给出「快捷键被占用，可在设置里换一个」类中文提示
- **AND** 应用其余功能正常启动，其他热键仍可用

#### Scenario: 更新失败回滚

- **WHEN** 用户把热键从 A 改为 B，而 B 注册失败
- **THEN** 系统 MUST 回滚为 A，并保持 A 可触发
- **AND** 设置中展示的仍是 A

### Requirement: 热键状态对外可见

应用 MUST 通过状态查询与状态广播向前端暴露该热键的当前绑定值，未知/未绑定 MUST 表示为空；状态变更（注册、清空、回滚）后 MUST 通知前端更新。

#### Scenario: 状态查询

- **WHEN** 前端请求热键状态
- **THEN** 返回值 MUST 包含直达知识库热键的当前组合（未绑定时为空）
- **AND** 设置页据此显示绑定状态

#### Scenario: 状态广播

- **WHEN** 热键注册成功、被清空或被回滚
- **THEN** 应用 MUST 广播最新热键状态，设置页无需重启即可更新显示

### Requirement: 触发后显示主界面并导航到知识库

触发该热键后，系统 MUST 先确保主窗口可见（已存在则显示并获得焦点，未存在则创建），再导航到知识库视图；主窗口已显示时 MUST NOT 重复创建窗口。

#### Scenario: 主窗口隐藏时触发

- **WHEN** 主窗口已隐藏到托盘，用户按下直达知识库热键
- **THEN** 主窗口显示并获得焦点
- **AND** 当前视图切为知识库（`#/kb`）

#### Scenario: 主窗口已显示

- **WHEN** 主窗口正在展示其他页面，用户按下该热键
- **THEN** 不新建窗口，直接切到知识库视图

#### Scenario: 前端导航监听

- **WHEN** 后端发出导航事件
- **THEN** 前端 MUST 校验目标路由是否在白名单内，合法则切换 hash 路由，非法则忽略
- **AND** 导航事件 MUST NOT 导致界面崩溃或空白

### Requirement: 主窗口打开命令支持目标路由

打开主窗口的命令 MUST 接受可选目标路由参数，前端传入的路由 MUST 生效；未传路由时 MUST 保持打开上次/默认视图。

#### Scenario: 带路由打开

- **WHEN** 前端请求「打开主窗口」并传入知识库路由
- **THEN** 主窗口显示后直接停在知识库视图

#### Scenario: 不带路由打开

- **WHEN** 前端请求「打开主窗口」且不传路由
- **THEN** 行为与改动前一致，不强制切换视图
