# knowledge-base/export Specification

## Purpose

让知识库文档离开应用后仍保持结构：把一篇文档导出为 Word（`.docx`）或 PDF（`.pdf`），由用户决定写到哪个目录，默认落在系统下载位置；Word 与 PDF 共用同一套入口、路径选择与只读语义。

## Requirements

### Requirement: 详情页提供单篇导出入口

知识库详情页 SHALL 在工具条提供「导出」入口，且一次只能导出一篇当前打开的文档；未打开文档或正文为空时该入口 MUST 不可用。

#### Scenario: 打开文档后可导出

- **WHEN** 用户打开一篇正文非空的文档
- **THEN** 工具条出现可点的「导出」按钮

#### Scenario: 正文为空时禁用

- **WHEN** 当前文档正文只有空白字符
- **THEN** 「导出」按钮呈禁用态，点击不发起任何导出

#### Scenario: 一次只导出一篇

- **WHEN** 用户在某篇文档上触发导出
- **THEN** 只生成这一篇的 `.docx`，不会顺带导出同目录其他文档

### Requirement: 导出前由用户选择目标位置

导出 SHALL 先弹系统保存对话框，默认文件名为 `<文档标题>.docx`、默认目录为系统下载目录；用户取消对话框时 MUST 不发生任何写盘，也不产生错误提示。

#### Scenario: 默认落在下载目录

- **WHEN** 用户首次触发导出
- **THEN** 保存对话框以系统下载目录为默认目录、以 `<文档标题>.docx` 为默认文件名

#### Scenario: 用户改到别的目录

- **WHEN** 用户在对话框里切到另一个目录并确认
- **THEN** 文件写到该目录，文件名沿用对话框中的值

#### Scenario: 取消不写盘

- **WHEN** 用户在保存对话框中点取消
- **THEN** 不创建任何文件，界面无错误提示

### Requirement: 导出保留文档结构与行内样式

导出的 `.docx` MUST 保留标题层级、段落与换行、行内加粗/斜体/行内代码/链接、有序与无序列表（含嵌套缩进）、引用块、代码块、表格（含表头）与图片；代码块 MUST 使用等宽字体，MUST NOT 承诺语法高亮配色。

#### Scenario: 标题与段落

- **WHEN** 正文含 `#`/`##`/`###` 标题与普通段落
- **THEN** Word 中对应为「标题 1/2/3」样式段落与正文段落，层级与原文一致

#### Scenario: 行内样式

- **WHEN** 段落里有 `**加粗**`、`*斜体*`、`` `代码` `` 与 `[文字](链接)`
- **THEN** 对应文字分别呈加粗、斜体、等宽、可点击超链接，其余文字不受影响

#### Scenario: 列表与引用

- **WHEN** 正文含有序列表、无序列表、嵌套一层的子项与 `>` 引用块
- **THEN** Word 中呈现对应的编号/项目符号与逐级缩进，引用块带左侧竖线与缩进

#### Scenario: 表格

- **WHEN** 正文含带表头的 Markdown 表格
- **THEN** Word 中生成同样行列的表格，首行按表头加粗，单元格文本不丢字

#### Scenario: 代码块

- **WHEN** 正文含围栏代码块
- **THEN** Word 中为等宽字体、保留换行与空格的独立段落块，不套用正文行距

### Requirement: 图片随文档嵌入

正文中的 `assets/<文件名>` 图片 MUST 作为内嵌图片写入 `.docx`，并保持原始宽高比、按页面可用宽度等比缩放；图片文件缺失或读取失败时 MUST 以 alt 文案占位并继续导出，MUST NOT 中断整篇导出。

#### Scenario: 图片正常嵌入

- **WHEN** 正文含一张 `assets/<sha>.<ext>` 图片且文件存在
- **THEN** 导出的 `.docx` 内嵌该图片，显示宽度不超过正文可用宽度且不变形

#### Scenario: 图片缺失

- **WHEN** 正文引用的图片文件已被删除
- **THEN** 该位置以 alt 文案（无 alt 时用 `[图片缺失]`）占位，文档其余部分照常导出并成功落盘

### Requirement: 文件名与失败处理

导出文件名 MUST 去掉 Windows 不允许的字符（`< > : " / \ | ? *`）并把连续空白折叠为一个；目标文件已存在时 MUST 由保存对话框承担覆盖确认；写入失败 MUST 返回中文短句错误、MUST 保持原文件不被截断。

#### Scenario: 标题含非法字符

- **WHEN** 文档标题为 `周报/2026: 第三季度`
- **THEN** 保存对话框的默认文件名不含 `/` 与 `:`，可正常保存

#### Scenario: 覆盖同名文件

- **WHEN** 用户选择一个已存在的 `.docx` 并在系统确认框里同意覆盖
- **THEN** 文件被新内容替换，不出现两个同名文件

#### Scenario: 写入失败

- **WHEN** 目标目录不可写（例如只读盘或权限不足）
- **THEN** 界面提示中文短句错误，目标位置不留下半截文件

### Requirement: 导出不改变知识库数据

导出 MUST 只读：MUST NOT 修改正文、图片资源、条目元数据或备份文件；MUST NOT 依赖网络。

#### Scenario: 导出后数据不变

- **WHEN** 用户导出成功后再打开同一篇文档
- **THEN** 正文、图片与条目更新时间都与导出前一致

#### Scenario: 离线可用

- **WHEN** 机器完全断网
- **THEN** 导出照常完成，不出现网络相关错误

### Requirement: 详情页可把当前文档导出为 PDF

知识库详情页 SHALL 提供「导出为 PDF」动作，把当前条目的正文导出为一个 `.pdf` 文件。该动作 MUST 与 Word 导出并列出现在文档工具条的动作区，MUST 有可读的中文名称或 `aria-label`；正文为空时该动作 MUST 处于禁用状态，MUST NOT 打开保存对话框。

#### Scenario: 从详情页导出 PDF

- **WHEN** 用户在一篇有正文的文档上点击「导出为 PDF」
- **THEN** 系统 SHALL 先弹出保存对话框，确认后在用户选定位置生成一个 `.pdf` 文件
- **AND** 导出过程中按钮 MUST 显示进行中状态，MUST NOT 被重复触发

#### Scenario: 空正文不可导出

- **WHEN** 当前条目正文为空或只有空白字符
- **THEN** 「导出为 PDF」MUST 处于禁用状态，点击不产生保存对话框，也不产生文件

#### Scenario: 非 Windows 构建不暴露该能力

- **WHEN** 应用运行在不提供 WebView2 打印能力的平台上
- **THEN** 「导出为 PDF」MUST NOT 出现在工具条上，调用同名命令 MUST 返回中文错误而不是崩溃

### Requirement: PDF 导出选择目标路径并默认落在下载目录

导出 PDF SHALL 通过系统保存对话框让用户选择目录与文件名；对话框的默认文件名 MUST 为 `<标题>.pdf`（标题经文件名清洗，非法字符替换为空格），默认目录 MUST 为系统下载目录，过滤器 MUST 只列 `pdf`。用户取消对话框时系统 MUST 什么都不做，MUST NOT 生成文件或报错。

#### Scenario: 默认落在下载目录

- **WHEN** 用户触发 PDF 导出且未改动对话框
- **THEN** 文件 MUST 写入系统下载目录，文件名为清洗后的标题加 `.pdf`

#### Scenario: 取消不产生副作用

- **WHEN** 用户在保存对话框里点取消
- **THEN** 系统 MUST 静默返回，不生成文件、不显示错误、不改变任何设置

#### Scenario: 目标目录不可写

- **WHEN** 用户选择的目录没有写入权限
- **THEN** 系统 MUST 显示中文短句说明换一个位置，MUST NOT 在目标目录留下临时文件或半截文件

### Requirement: PDF 内容与阅读视图结构一致

PDF 的内容 SHALL 由当前文档正文生成，排版 MUST 覆盖标题层级、段落与行内强调、列表、引用、代码块、表格与图片。生成 MUST 使用与阅读视图相同的 Markdown 解析配置；图片 MUST 内嵌进 HTML 而不是依赖运行时可访问的路径；页面 MUST 为 A4、使用打印默认边距，且 MUST NOT 输出页眉页脚或页码。打印件 MUST 使用中性文档基线（白纸、黑字、只表达结构），MUST NOT 套用应用外观主题的纸色、墨色、圆角、斑马纹等屏幕皮肤，MUST NOT 混入应用外壳元素（侧栏、工具条、按钮）。

#### Scenario: 复杂文档导出后结构完整

- **WHEN** 导出包含标题、列表、引用、代码块、表格与图片的文档
- **THEN** PDF MUST 页数大于 0，且逐项包含上述结构的内容
- **AND** 中文 MUST 正常显示，MUST NOT 出现方框或乱码

#### Scenario: 图片内嵌

- **WHEN** 文档含本地图片
- **THEN** 图片 MUST 出现在 PDF 中，且导出完成后 MUST NOT 依赖原图片路径仍然可读

#### Scenario: 只打印正文

- **WHEN** 文档在应用内导出
- **THEN** PDF 页面 MUST 只包含文档正文与中性排版，MUST NOT 包含工具条、侧栏、按钮或应用外观主题的装饰

### Requirement: PDF 打印有超时与失败回退

打印 SHALL 在固定上限内完成，超时 MUST 判定为失败；打印回调报告失败、WebView2 运行时不满足要求、或临时资源准备失败时，系统 MUST 返回中文短句错误，MUST NOT 崩溃，MUST NOT 留下未完成的 `.pdf`。

#### Scenario: 打印超时

- **WHEN** 打印在超时上限内没有收到完成回调
- **THEN** 系统 MUST 关闭离屏窗口、清理临时文件并返回中文超时提示

#### Scenario: 打印回调失败

- **WHEN** WebView2 的打印完成回调报告 `isSuccessful = false`
- **THEN** 系统 MUST 返回中文失败提示，且目标路径 MUST NOT 出现损坏的 PDF

#### Scenario: 连续导出

- **WHEN** 用户先后导出两次 PDF
- **THEN** 两次 MUST 各自成功，第二次 MUST NOT 因为上一次的离屏窗口或用户数据目录被占用而失败

### Requirement: PDF 导出不改变文档与设置

导出 PDF SHALL 是只读操作：MUST NOT 修改条目的正文、标题、更新时间或排序，MUST NOT 写入 `data.json`，MUST NOT 改变导出目录之外的任何用户设置。

#### Scenario: 导出后数据不变

- **WHEN** 用户导出一次 PDF 后重新打开该条目
- **THEN** 正文、标题与更新时间 MUST 与导出前一致
- **AND** 数据目录下的 `data.json` MUST 未被导出操作改写

### Requirement: 导出格式覆盖 Word 与 PDF

知识库文档导出能力 SHALL 同时覆盖 `.docx` 与 `.pdf` 两种格式：两种格式 MUST 共用同一套入口位置、标题清洗规则、默认下载目录与保存对话框交互；任一种格式失败时 MUST NOT 影响另一种格式的可用性。

#### Scenario: 两种格式共用同一套交互

- **WHEN** 用户分别导出同一篇文档的 Word 与 PDF
- **THEN** 两次的默认文件名 MUST 都是清洗后的同一标题（仅扩展名不同），默认目录 MUST 都是系统下载目录

#### Scenario: 一种格式失败不影响另一种

- **WHEN** PDF 导出因运行时不可用而失败
- **THEN** 导出 Word MUST 仍然可用并成功，且失败提示 MUST 指明是 PDF 这一种格式出了问题
