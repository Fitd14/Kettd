# editor/heading-select Specification

## Purpose
让编辑器标题级别选择器使用与应用纸面主题一致的浮层，同时保持键盘可操作、可访问，并且不抢占编辑器选区。

## Requirements

### Requirement: 选项集合与编辑语义

标题选择器 MUST 提供「正文 + H1–H6」七个选项。选择「正文」SHALL 将当前块设为普通段落；选择 H1–H6 之一 SHALL 对当前块应用对应级别标题的切换语义（已是该级别则取消回正文）。选择器显示值 MUST 反映当前光标所在块的标题级别。H5 / H6 MUST 具备可辨识的字号层级（沿用编辑器与阅读态既有 h5/h6 样式）。

#### Scenario: 正文转 H2

- **WHEN** 当前块为正文，用户选择「H2」
- **THEN** 当前块变为二级标题，选择器显示「H2」

#### Scenario: H2 转正文

- **WHEN** 当前块为二级标题，用户选择「正文」
- **THEN** 当前块恢复为普通段落

#### Scenario: 光标移动同步显示值

- **WHEN** 用户在正文、H1–H6 之间移动光标
- **THEN** 选择器显示值随当前块级别更新，未打开不再残留旧值

#### Scenario: 再次选择同级标题

- **WHEN** 当前块已是 H2，用户再次选择「H2」
- **THEN** 按标题切换语义该块取消标题、回到正文，选择器显示「正文」

### Requirement: 自绘浮层与主题一致性

选择器的展开列表 MUST 由应用自绘，MUST NOT 依赖操作系统绘制的原生下拉弹层。浮层颜色、字号、圆角、阴影 MUST 取自应用既有设计令牌（颜色仅允许 `hsl(var(--token))` 或 `var(--token)`），MUST NOT 引入裸色值或第二套主题令牌。浮层 MUST 在亮色与暗色主题下都可读，MUST NOT 被编辑器滚动容器或窗口边缘裁剪。

#### Scenario: 暗色主题下展开

- **WHEN** 应用处于暗色主题，用户打开标题下拉
- **THEN** 浮层背景、文字与高亮项使用暗色 token，不出现白底原生列表

#### Scenario: 靠近窗口底部打开

- **WHEN** 编辑器位于窗口底部附近，用户打开标题下拉
- **THEN** 浮层完整可见（向上翻转或限制在视口内），不被窗口边缘裁掉

#### Scenario: 不被编辑区裁剪

- **WHEN** 编辑器容器存在滚动或 `overflow` 限制，用户打开标题下拉
- **THEN** 浮层仍完整显示在编辑器之上

### Requirement: 键盘与指针交互

下拉打开后 MUST 支持键盘操作：↑ / ↓ 在选项间循环移动高亮，Enter 应用当前高亮项，Esc 关闭并还原触发按钮上的焦点；鼠标移动可以改变高亮项，点击选项应用该项。点击浮层外部 MUST 关闭浮层且不应用任何选项。浮层打开时再次点击触发按钮 MUST 关闭浮层。

#### Scenario: 方向键循环

- **WHEN** 下拉打开且高亮在最后一项，用户按 ↓
- **THEN** 高亮回到第一项；高亮在第一项时按 ↑ 回到最后一项

#### Scenario: Enter 应用

- **WHEN** 下拉打开且高亮在 H3，用户按 Enter
- **THEN** 当前块应用 H3，浮层关闭

#### Scenario: Esc 关闭并还焦

- **WHEN** 下拉打开，用户按 Esc
- **THEN** 浮层关闭，焦点回到标题触发按钮，不应用任何选项

#### Scenario: 点击外部关闭

- **WHEN** 浮层打开，用户点击浮层与触发按钮之外的区域
- **THEN** 浮层关闭，编辑器内容与选区不变

### Requirement: 不抢占编辑器选区

打开、关闭或悬停标题下拉 MUST NOT 改变编辑器当前选区。触发按钮与浮层选项的鼠标按下 MUST 阻止默认焦点转移，使应用选项时仍作用于打开下拉前的选区。

#### Scenario: 选中文字后应用标题

- **WHEN** 用户在编辑器中选中一段文字，打开标题下拉并选择「H2」
- **THEN** 选中的文字变为 H2，选区与光标位置不被无关地重置到文首或文末

#### Scenario: 打开下拉不丢选区

- **WHEN** 编辑器中有选区，用户点击标题触发按钮展开下拉
- **THEN** 编辑器选区保持可见且未被折叠到文档边界

### Requirement: 可访问性

标题选择器 MUST 暴露可访问性语义：触发按钮带 `aria-haspopup` 与可读名称「标题级别」，展开列表为 `role="listbox"`，选项为 `role="option"` 并标注当前选中项；键盘焦点 MUST 有可见的焦点指示，焦点环对比度 MUST 不低于 3:1。

#### Scenario: 读屏可识别

- **WHEN** 用户使用读屏聚焦标题选择器并展开
- **THEN** 读屏可识别「标题级别」按钮与「正文、H1–H6」选项列表，并播报当前选中级别

#### Scenario: 键盘焦点可见

- **WHEN** 用户用键盘聚焦标题选择器或移动下拉高亮
- **THEN** 焦点位置有可见指示，且与背景对比度不低于 3:1
