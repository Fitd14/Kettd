Kettd · design-review · v1

按钮体系：一套尺寸、一套变体

把散在 8 组专用类里的按钮收成 ui/button 的 3 档尺寸 × 6 个变体。原生 <button> 只允许出现在这个封装内部；页面改调 <Button variant size>。本页只用现有令牌，不含新配色。

01 · 为什么现在不一致

空转类名

.btn.outline 用了 22 处、.btn.primary 4 处，但全局 CSS 里没有定义 —— 只有 capture.css:114（.cap-frame）和 settings-backup.css:203（.backup-dialog）两处页面作用域补丁。这些按钮实际渲染成默认描边样式。

12 组按钮类各写各的

.btn 6px 圆角 / .kb-editor-tool、.kb-strip-btn 4px / .sticky-btn 8px；高度 19 / 20 / 21 / 22 / 24 / 28 / 32 七种；hover 有 --muted、currentColor 12%、便签里又是 hsl(0 0% 50% / .14)。其余：.kb-find-btn .kb-folder-caret .kb-folder-add .kb-folder-action .kb-tag-x .kb-pin-row .todo-mini-btn .sticky-md-btn。

字号三档乱入

同一屏里按钮字号 11px（.btn.xs）、12.5px（.btn、工具条）、14px（.sticky-btn）并存；点击区最小只有 16×20，低于触控与可读下限。

02 · 变体

6 个变体覆盖全部用途

每个变体只改颜色与边框，尺寸、圆角、焦点环完全共用。默认档 sm；密集行内用 xs；对话框主操作、页面主操作才用 md。

default

22 处 outline → 这里
描边 1px · hover 填 --muted

primary

对话框主操作
实心 --primary · hover 88%

ghost

行内、工具条、图标
无边框 · hover 填 --muted

soft

分段、次主操作
填 --secondary · 无边框

danger

删除、清空、危险确认
红描边 / 红实心两档

pressed

工具条激活、分段选中
用 aria-pressed 表达，不新增 .on

4 项
  • 尺寸上移：xs 从 17px 提到 22px、字号 11→12.5px；工具条 24→26px。接受这点视觉变高吗？
  • primary 实心：全局补上主按钮样式（现在是空转类），只在对话框主操作与页面主操作使用。
  • 便签按钮：沿用 [data-surface="sticky"] 换色，尺寸与圆角跟随全局，不再单独 8px / 14px。
  • 窗口按钮：保留 44×32 无圆角与 close 红，不走 size 阶梯，单独 size="window"。

审查通过后：先落 ui/button.tsx 与 ui/icon-button 两个文件 → 再按批替换 161 处；每批跑 npx tsc -b + 真机截图。
