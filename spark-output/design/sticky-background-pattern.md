---

## 1. 设计判断（先说清楚张力）

| 立场 | 内容 |
| --- | --- |
| 用户愿景 | 纸面融入竹子、山水等中国传统意象 |
| 现有设计语言 | 现代便签 = 暖纸 + 留白 + 琥珀图钉 + 折角（安静文具） |
| **调和原则** | 中式意象以「水墨留白」进入：**淡如水印、让位于字、构图取角**。水墨画的核心本来就是留白——这与 Minimalism 准则同向，不冲突；冲突的只有「满铺重纹」，本稿不做 |

## 2. 三个方向

### 方向 A「墨竹一枝」（推荐）

- **构图**：左下角竖出一丛墨竹——2 竿竹竿（细描边）+ 5-7 片竹叶（叶形填充），高约占纸面 40%，宽 ≤22%；右下折角区留空
- **笔意**：SVG 描边模拟毛笔（竿用 2px 渐细线、节间留节环），**不是**卡通竹
- **浓度**：墨色 7% 透明水印；悬停/完成行底色照常盖在其上

```
┌ 便签 ──────────────┐
│ ✎ 今天要做的 · 2  ✕ │
│ ☑ 任务甲            │
│ ┈┈┈┈┈┈┈┈┈┈┈┈┈ │
│ ☐ 任务乙        叶 ↘│
│ ☐ 任务丙      竹竿│ │
│ ┈┈┈┈┈┈┈┈┈┈ ║ │
│              竹 ║ │
└──────────────────┘
   ↑ 竹在文字后层，不随列表滚动
```

### 方向 B「远山横带」

- **构图**：纸面底部 2-3 层山峦剪影横带（近坡 + 远山 + 更远一抹），高 72-90px，山脊线用平滑曲线，层与层用墨色 5%/7%/9% 三档拉开纵深——最贴「山水画」的意象
- **气质**：比竹更含蓄，列表长时文字会压在山上（透明度足够低则无碍）
- **风险**：与右下折角轻微相接，需把折角区域的山做淡出

### 方向 C「朱印小品」

- **构图**：折角上方一枚 14×14px 朱砂小印（篆意「记」字或抽象回纹），全纸面唯一彩点
- **气质**：最克制、最「文人」；但不满足用户对「竹/山水」的直接期待，可作为 A/B 的伴随元素而非替代

## 3. 技法与适配（三个方向通用）

| 项 | 方案 |
| --- | --- |
| 载体 | 内联 SVG（约 1-2KB）绝对定位贴 `.sticky-note`，`z-index` 在列表层之下；**纸面纹样不随列表滚动**（纸的纹理是固定的） |
| 用色 | 全部 `color-mix(in srgb, var(--sticky-ink) N%, transparent)`——暖白/牛皮/淡青上自动呈淡墨，暗墨纸上自动呈浅亮，**四纸色一处定义全适配** |
| 可读性红线 | 纹样峰值浓度 ≤9%；正文墨色对「纸+纹样最深处」取色复测 ≥4.5:1（纹样只带来 ≤3% 亮度扰动，余量充足） |
| 淡化态 | 纹样随整窗 38% 淡化同步变淡（纸的一部分），无需单独处理 |

## 4. 纸色 × 纹样的关系（需要拍板的第二个问题）

| 选项 | 行为 | 评价 |
| --- | --- | --- |
| **绑定式（推荐）** | 纸色自带伴生纹样：暖白=远山、牛皮=墨竹、淡青=竹影、暗墨=远山 | 零新设置，换纸色即换意境，符合 §12.1「少即是多」 |
| 独立设置 | 新增「花纹」选择（无/竹/山/印） | 灵活但违背「纸色四选是唯一新增设置项」的定稿倾向 |
| 固定一款 | 所有纸色同一纹样 | 最简单，但淡青配远山、牛皮配远山不如竹对味 |

## 5. 验收标准（实施后）

1. 纹样只出现在纸面留白处，任何待办文字可读性实测 ≥4.5:1
2. 纹样不随列表滚动、不遮勾选框/取下钮/折角
3. 四套纸色切换纹样颜色自适应，暗墨纸上同样成立
4. 淡化态（38%）下纹样同步变淡
5. 变更范围：`sticky.css` + `StickyWindow.tsx` 内联一段 SVG（或独立 .svg 资源），Rust 零改动
