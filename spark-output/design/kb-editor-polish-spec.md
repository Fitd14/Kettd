# kb 编辑器打磨设计（editor-polish-spec）

> 2026-09-10 · 基于 audit/kb-editor-体验走查.md 5 机会点 + 竞品对照（Typora/Notion/Obsidian/语雀）
> 目标：修复 owner 五问题（模式分离/编辑差/阅读差/无提示/无表格），把 KB 详情升级为 Typora 级即时渲染画布。

## 1. 核心架构决策：单一即时渲染画布（去模式化）

**现状**：阅读/编辑双模式按钮 + 阅读态点击误触进编辑 + 切换丢滚动 + 编辑器重挂载。

**设计**：
- **去掉「阅读/编辑」模式与按钮**。TipTap 画布常驻，**所见即所编辑**——内容永远以成品样式呈现，点击即定位光标继续写。
- 「阅读感」由 §5 排版体系承担，不再由模式承担（Typora 验证的形态）。
- **不设防**（默认决策，可改）：不提供"只读锁"。误改风险由既有兜底承担（自动保存 + 写前轮转备份）。Typora/Notion 均不设防，符合"安静文具"定位。
- 保存机制不变（800ms 防抖自动保存），新增保存状态指示（§4）。

**详情面板新结构**（自上而下）：
```
┌──────────────────────────────────────────────┐
│ 工具栏：⟨ │B I H1 H2 • 1. ❝ </> ☐ │⊞表格 ⛓ │ 📌 📝 🗑 │
├──────────────────────────────────────────────┤
│ 标题（就地编辑，超大字号）            [已保存 21:32] │
│ 标签：#rust ×  #笔记 ×  [+标签]                     │
├──────────────────────────────────────────────┤
│                                            │
│   即时渲染画布（正文即成品，点击即写）                │
│                                            │
└──────────────────────────────────────────────┘
```

## 2. 表格全能力

- **依赖**：`@tiptap/extension-table` + `table-row` + `table-cell` + `table-header`（本地 bundle）。
- **创建三路径**（竞品三路径全上）：
  1. 工具栏「表格」钮 → **网格选择器**（3×3 起步，鼠标悬停扩展行列，点击插入——Typora Ctrl+T / Notion 同款交互）
  2. **Cmd/Ctrl+T** 快捷键直接弹网格选择器
  3. slash 命令「/表格」（§3）
- **表内交互**：Tab/Shift+Tab 跳格（末格 Tab 新增行）；表格内点击出现**气泡菜单**（+行 −行 +列 −列 表头开关）；拖拽边缘调列宽（TipTap columnResize，若 v3 就绪则上，否则降级固定均宽——实施时验证）。
- **Markdown 往返**：tiptap-markdown 表格序列化为 GFM 语法；md-fidelity 测试补表格样本（含表头/对齐/空格）。

## 3. 提示体系

- **slash 命令面板**（Notion 式，`@tiptap/suggestion` 自实现）：
  - 空行或文字后输入 `/` 弹出面板：表格、无序列表、有序列表、任务列表、引用、代码块、标题 1、标题 2、分割线
  - 键盘 ↑↓ 导航 + Enter 确认 + Esc 关闭；继续输入即过滤（拼音首字母匹配可选，一期不做）
  - 每项带 lucide 图标 + 一句用途说明（识别优于回忆）
- **选区浮动工具栏**（BubbleMenu）：选中文字即弹出——加粗 / 斜体 / 行内代码 / 删除线（高频四件，不做全量）
- **placeholder**：空文档「写点什么…（输入 / 唤起插入菜单）」
- **工具栏升级**：lucide 图标（Bold/Italic/Heading1/Heading2/List/ListOrdered/TextQuote/Code）+ 分组（格式 | 插入）+ title 补 kbd（如「加粗 Ctrl+B」）；右侧动作组（贴到桌面/转为待办/删除）保留

## 4. 元数据区与保存可见

- **标题就地编辑**：大字号无边框输入框（视觉上就是标题），失焦/Enter 保存 `updateKbItem(title)`，Esc 取消
- **标签增删**：chips 尾部 × 删除；「+ 标签」输入框（Enter 确认、Backspace 删末位）→ `updateKbItem(tags)` 整体提交
- **保存状态指示**：标题行右侧小字「编辑中…」⇄「已保存 HH:MM」（防抖触发前后切换；复用自便签窗"已保存"心智）
- 元数据区与正文间细分隔线，阅读时元数据弱化（muted）

## 5. 阅读排版体系（去模式后阅读感的承担者）

- **字号阶梯**（画布内）：正文 0.95em/行高 1.75；h1 1.35em/上距 1.6em；h2 1.2em；h3 1.05em；段落间距 0.75em
- **阅读宽度**：画布内容 `max-width: 76ch`（长文不拉满，短文无感知）；面板内居左（与详情工具栏对齐，不做居中——工具类一致性优先）
- **代码块**：底色令牌、圆角、等宽 0.88em、横向滚动、右上角语言标签（data-lang 已有）
- **引用**：左侧 3px 墨线 + 淡墨字；**表格**：细边框令牌化、表头 secondary 底、单元格 padding 0.5em 0.8em、横向滚动兜底
- **列表**：任务列表 checkbox 可交互（TipTap 原生），渲染态与编辑态一致

## 6. 技术落点

- **新依赖**（全部本地 bundle，禁 CDN）：`@tiptap/extension-table` `-table-row` `-table-cell` `-table-header`、`@tiptap/suggestion`；BubbleMenu 在 `@tiptap/react` v3 内置（实施时确认，否则加 `-extension-bubble-menu`）
- **改动文件**：`tiptap-editor.tsx`（去 readOnly 分支、+表格/slash/bubble、工具栏 lucide 分组）、`kb-item-detail.tsx`（去模式、元数据区、保存指示）、`prosemirror.css`（排版阶梯+表格+slash 面板样式）、`kb-item-detail` 联动 `kb.css`、`package.json`
- **体积纪律**：表格+slash+bubble 估 +80KB gzip 级别，全部进主窗 chunk；**便签窗仍只载核心**（知识便签自动获得表格能力——共享内核同 chunk，mermaid 等重组件仍不进便签）
- **命令面**：零新命令，parity 59 不动；Rust 零改动

## 7. 不做什么（本期边界）

图片插入/上传、目录 TOC、Mermaid 渲染落地、协同编辑、拼音过滤 slash、移动端适配（桌面 App）——均列入后续增量台账。

## 8. 验收清单

| # | 验收项 |
|---|---|
| 1 | 进详情直接打字即成型，无阅读/编辑按钮，无点击误切模式 |
| 2 | 表格三路径创建（工具栏网格/Cmd+T//表格）；Tab 跳格；气泡增删行列；保存后 bodyMd 为 GFM 表格语法；往返保真样本通过 |
| 3 | 输入 / 弹面板、键盘导航可用、Esc 关闭、过滤生效 |
| 4 | 选中文字弹浮动条（B/I/行内代码/删除线） |
| 5 | placeholder 引导语显示；工具栏 title 带 kbd；图标全 lucide |
| 6 | 标题就地改名生效（主窗/知识便签同步）；标签可增删 |
| 7 | 「编辑中…/已保存 HH:MM」指示随防抖切换 |
| 8 | 排版阶梯生效（标题对比/宽度上限/代码块/表格样式） |
| 9 | 知识便签窗同步获得表格/提示能力（共享内核） |
| 10 | 门禁：tsc/vite/oxlint 绿 + md fidelity 表格样本 + parity 59 不动 |
