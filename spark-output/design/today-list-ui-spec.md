## A. 统一列表行组件 `<TaskRow>`（今天 / 收件箱 / 便签共用）

> 现状三处各用 `rowEl`/便签自绘，风格与动作不一致。抽成一套，避免规格重复。

### A.1 行结构（默认态，只保留"读"）
`[勾选框] [标题] [（可选）顺延/滞留 badge] …… [分类 chip]`
- **移除常驻动作按钮**：处理动作（→今天 / 排期 / ⋯ / 删除）默认不占位。

### A.2 状态变体
| 态 | 表现 |
|---|---|
| default | 仅读元素 |
| hover / focus | 行尾浮出紧凑动作（今天页：排期/⋯；收件箱：→今天/排期/⋯）；行底色 `--muted` 极淡 |
| done | 标题置灰 + 删除线 |
| carry/aged | 左侧**琥珀竖条** + 行内 badge「顺延 N 天」/「滞留 N 天」（`--pri-med` 系，**非红**） |
| savefail | 行内「没有保存 · 重试」（沿用现有） |

### A.3 统一规则（三处一致）
- **老化色 = 琥珀，不用红**：守"安静文具"调性；老化仅作温和压力，文字承载（"顺延/滞留 N 天"），色非唯一信息。
- **优先级点弱化**：只对手动设过的显优先级点；分类 chip 常驻（用于快速归类）。
- **拖拽**：整行可拖（输入/勾选/动作区排除）；今天/收件箱内 `sort_order` 排序；收件箱→今天 = drag-to-plan（`updateTask plannedDate`）。与便签 §12.2 同一套拖拽库。
- **键盘等价**：`j/k` 移动、`Enter` 展开、`T` 加入今天、`E` 排期、`X` 删除、`Space` 勾选；hover 动作必须有键盘等价（触屏点行展开详情承载动作）。
- **数据**：全部基于现有字段（`created_at` 派生老化、`plannedDate`/`dueAt` 判 carry、`priority`/`category`）。可选后端 `update_tasks(ids,patch)` 批量命令（性能，非必需）。

## B. 今天视图专项优化（对应 audit/today.md F1–F10）

### B.1 单一捕获入口（F1）
- 删掉顶部「快速记录（Alt+Shift+A）」独立按钮，只保留**一个内联输入框**，placeholder「记一条，回车放进今天（或按 Alt+Shift+A）」。

### B.2 合并主列表（F2/F3）
- 「今天要做的」不再按 fresh/carry 拆两段 → **一个列表**，carry 用 A.2 的行内琥珀 badge。
- 术语：「已拖到今天」→「**顺延**」（避开与"拖拽"撞词）。

### B.3 逾期：琥珀·不隐身（F4/F5）
- 底部「已逾期 N 项」由红色 destructive 改**琥珀折叠条**（点开：移到今天 / 清截止 / 删除）。
- 主列表上方或进度旁给一句逾期计数，别让逾期"隐身"。

### B.4 执行驾驶舱（F7/F9）
- 进度条下加一行「**下一条提醒 · HH:MM 标题**」。
- 进度旁注口径「今天计划 N 项」（`total = 今天done + 今天pending`）。

### B.5 规划路径分清（F6）
- 「可拉进今天」保留但标注为**快捷方式**；主路径 = 收件箱→处理（A.2/A.3 的 drag-to-plan 让快捷方式更快）。

### B.6 保留项（亮点）
- 空态 / 全完成态（"✓ 今天清空了" / "今天还是空的…"）不动。

## C. 可访问性（统一）
- 老化/逾期琥珀与背景对比 ≥3:1；文字承载非唯一色。
- 勾选框/动作键盘可达、`focus-visible` 环（`--ring`）。
- 拖拽有非拖拽替代（批量栏 / 行内动作 / 详情按钮）。

## D. 验收（Given/When/Then）
- AC1 三视图（今天/收件箱/便签）行样式与动作一致，默认无常驻按钮，hover/聚焦才出。
- AC2 今天只有一个捕获入口；carry 内联琥珀 badge、无独立"已拖到今天"段。
- AC3 逾期为琥珀折叠条、非红、有计数说明。
- AC4 今天顶部显示"下一条提醒"与进度口径。
- AC5 键盘可完成勾选/加入今天/排期/删除；拖到"今天"=加入今天。

## E. 工时（M3 估）
- `<TaskRow>` 统一组件（含 hover/老化/键盘/拖拽）~3h
- 今天专项（入口合并/列表合并/逾期琥珀/下一条/进度）~2h
- 收件箱套用同一组件（去重 inbox-ui-spec 里的行部分）~1h
- 可选 `update_tasks` 批量命令 ~1h
合计 ~6–7h（一次做通"统一列表语言"，三视图共享，比三处各改各的省）。

## F. 落地顺序建议
先做 §A 统一行组件（地基）→ 今天套用（§B）→ 收件箱/便签回接（去重）。这样"统一列表语言"一处定义、三处复用，规格不再各写各的。
