# 设计规格 · Kettd 回顾页重设计（场景A 数据分析/BI）

- 状态：**定稿（2026-09-04）** · 听众：实现者（M3）· 组件库：shadcn/ui + 自研组件
- 关联：`spark-output/context/brief.json`、`sitemap.json`、`timeline-component-spec.md`、`ADR-001`（`src-tauri/docs/ADR-001-frontend-react-migration.md`，React 迁移 M3）
- 边界：本文档**只做设计规格，不含实现代码**。回顾页在 v2 现状是「日志簿 / 周汇总草稿」两 tab，本次重设计引入 **年热力图 + 横向时间轴 + 点某天下钻**。

---

## 1. 目标与范围

- **目标**：把「回顾」从"读文字流水"升级为"看得见的节奏"——一眼看全年完成密度（热力图）、按时间顺序回看执行（时间轴）、点某天看当天完成（下钻）。对齐 brief 目标「完成记录 100% 入日志、可回看」。
- **范围内**：S1 回顾总览（KPI + 周期 Tabs + 年热力图 + 横向时间轴）、S2 某天完成 Sheet。
- **范围外（本次不重画）**：周汇总草稿（`reviewWeekly`）保留为页内次级入口，不改；不引入云同步/遥测。

## 2. 数据契约（实现强依赖，字段均已存在于 `Task` 模型）

| 用途 | 字段 | 规则 |
|---|---|---|
| 热力图/时间轴/下钻的时间锚点 | `done_at`（RFC3339 本地时刻） | 按 `done_at` 的**日期**聚合；按 `done_at` **时刻**排序 |
| 排除回收站 | `deleted_at` | 非空 = 在回收站，**不计入**任何统计 |
| 分类上色 | `category`（工作/学习/生活） | 圆点/格子 hover 用分类色 |
| 优先级 | `priority` | 本页**不展示**（按定稿，仅信息展示） |
| 准点/逾期 | `due_at` vs `done_at` | 本页**不展示**（按定稿移除该标签） |
| 周起点 | `week_start` 契约 | 热力图列=周、行=周一..周日，复用既有 `week_start` |
| 诚实处理 | `legacy`（v1 无 `done_at` 的完成） | **不进格子、不进时间轴**；KPI 单列「无日期完成 N」，脚注说明不伪造日期 |

**聚合口径**
- 热力格强度 = 当天 `done_at` 完成数（排除 `deleted_at`、排除 `legacy`），5 档：`0 / 1-2 / 3-5 / 6-9 / 10+`（阈值可配）。
- 时间轴 = 全部有 `done_at` 的完成项，按 `done_at` **倒序**（最近在前）。
- 下钻某天 = `done_at` 落在该日的完成项（仅此，不含新建/逾期）。

## 3. 页面布局（单页 · 响应式）

```
┌ S1 回顾总览（横向，占内容区）──────────────────────────┐
│ [KPI 条] 本周完成 · 连续打卡 · 本年总计 · 无日期完成     │
│ [周期 Tabs]  年(默认) | 近90天 | 本月                    │
│ [年热力图 53×7]  ← 窄容器时横向滚动                      │
│ ─────────────────────────────────────────────          │
│ [完成时间轴 · 横向滚动 · 默认内嵌]  ← 见组件规格         │
└────────────────────────────────────────────────────────┘
   点热力格 ──▶  S2 某天完成 Sheet（右侧滑出，竖向覆盖层）
```

- **导航**：沿用既有侧栏（今天/收件箱/计划/**回顾**/设置），回顾页只重设计内容区。
- **S2 是覆盖层（Sheet/Dialog），不是新页面/新路由**。

| 区块 | 组件 | 来源 |

## 5. 交互态

- **点热力格**：`done_at` 该日有完成 → 打开 S2 Sheet（标题「YYYY-MM-DD 周X · 完成 N 项」，列表只列当天完成项，每项 标题 + 分类 chip）；该日 0 完成 → 格子不可点或点之提示「当天无完成」。
- **时间轴节点点击** → 复用既有任务详情。
- **横向滚动**：时间轴与（窄容器下的）热力图各自横向滚动，不撑破窗口。
- **三终态**：Success 空态（新用户无完成 → 引导「完成一件事后这里会长出格子」）；Error（数据读取失败 → 提示 + 重试）；Abandon（Sheet/滚动中途关 → 回总览，选中态清空）。

## 6. 响应式与窗口（关键）

- 主窗口 `resizable:true`，`minWidth:1024 / minHeight:640`（现状已具备）→ 用户可**手动拖拽缩放**，页面须在 **1024px 起**回流。
- 内容区可用宽 = 窗口宽 − 侧栏（~200）− 内边距；年热力图 53 周 × ~16px ≈ 848px，**可用宽 < ~880 时热力图横向滚动**（默认滚到最新周）。
- 时间轴恒定横向滚动（节点数不受窗口宽限制）。
- 断点建议：`<1100` 收紧 KPI 为 2×2；`<1024` 不允许（有 minWidth 兜底）。

## 7. 可访问性（WCAG 2.1 AA）

- 热力格 5 档绿 + 分类色点：与背景对比 ≥3:1（非文本），并**提供非颜色冗余**（hover Tooltip 文本 + 分类 chip 文字），防色盲。
- 时间轴节点可 Tab 聚焦、方向键横向滚动、`focus-visible` 环；格子可键盘进入下钻。
- 时间标签 `MM-DD HH:mm` 用 `<time datetime>` 语义。

## 8. 验收标准（Given/When/Then）

- AC1 热力图：Given 有跨多月的完成，When 打开回顾，Then 年网格按天完成数分 5 档着色，`legacy`/回收站不计入且脚注显示「无日期完成 N」。
- AC2 下钻：Given 点某天格子，When 该日有完成，Then 右侧 Sheet 只列当天 `done_at` 完成项（无新建/逾期）。
- AC3 时间轴：Given 多条完成，When 查看，Then 横向时间轴默认内嵌、按 `done_at` 倒序最近在最左、可横向滚动、底部 loading 加载更早。
- AC4 响应式：Given 把窗口从 1024 拖到更宽，When 缩放，Then 页面无横向溢出破版，热力图/时间轴按需横向滚动。
- AC5 a11y：Given 键盘操作，When Tab/方向键，Then 格子与时间轴节点可达、焦点可见、颜色非唯一信息载体。

## 9. 实现决策提示（供 M3）

- **组件库一致性**：时间轴「参考 Ant Design Timeline」，但为不引入 antd 整包、保持单一设计系统，建议**用 shadcn token 自研一个 Ant-Timeline 兼容的 `CompletionTimeline`**（API/视觉对齐 Ant v6），而非直接依赖 `antd`。若后续整体引入 antd 再替换。详见组件规格 §决策。
- 数据侧：热力/时间轴/下钻全部走 `done_at` 聚合，建议后端加一个 `get_review_stats(range)` 命令返回按日聚合 + 完成流水，避免前端拉全量任务自己算（也可前端算，量小）。
