# UI 设计文稿 · 便签待办行打磨（分割线 + hover 下划线）

- 状态：**已定稿实施**（方案 A + 加分项全做）· 2026-09-08
- 对象：便签窗待办行（`src-react/src/sticky/sticky.css`，仅 CSS 两处，不动 Rust / 窗口结构）
- 设计基调：便签规格 §5「现代便签」——暖纸、安静文具、琥珀点缀；分隔要轻，不抢纸面

---

## 1. 现状与问题

| 现状（sticky.css） | 问题 |
| --- | --- |
| `.sticky-row { padding: 5px 4px }` 无边框 | 行与行之间零分隔，两条以上待办时糊成一片，空荡 |
| `.sticky-title:hover { text-decoration: underline }` | 悬停出下划线，与「现代便签」纸面语言不符（下划线是网页链接的语言，不是文具的语言） |
| `.sticky-gap`（镜像/钉住组间）= 22% 虚线 | 保留；它是**组间**分隔，应比行间线重一档（现状没问题，作层级锚点） |

## 2. 方案对比（分割线）

| 方案 | 样子 | 判定 |
| --- | --- | --- |
| **A. 发丝实线（推荐）** | 1px、墨色 9% 透明的细线，通栏贯穿 | 安静、现代、四纸色自适应 ✅ |
| B. 虚线 | 与组间虚线同语言 | ❌ 和组间分隔打架，层级变模糊 |
| C. 斑马纹交替底色 | 隔行浅底 | ❌ 噪感重，破坏纸面干净 |

## 3. 定稿规格（方案 A）

```css
/* ① 行间发丝线：相邻行才有，首行上方/末行下方自然无线 */
.sticky-row + .sticky-row {
  border-top: 1px solid color-mix(in srgb, var(--sticky-ink) 9%, transparent);
}

/* ② 行距呼吸感：5px → 6px（垂直），配合分割线形成「一行一格」的节奏 */
.sticky-row { padding: 6px 6px; }

/* ③ 去掉标题下划线（hover 反馈由整行淡底色承担，不符合「只删不给」红线） */
.sticky-title:hover { text-decoration: none; }   /* 即删除原规则 */
```

## 4. 层级与适配说明

```
┌ 便签（牛皮纸示例）────────────┐
│ ✎ 今天要做的 · 2 · 做完 1   ✕ │ ← 自绘胶条
│ ☑ 任务甲                     │
│ ┈┈ 1px 墨色9%发丝线 ┈┈┈┈┈┈ │ ← 行间：轻（9% 实线）
│ ☐ 任务乙                     │
│ ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈ │
│ ☐ 任务丙                  ×  │
│ ⋯⋯ 22% 虚线（组间）⋯⋯⋯⋯ │ ← 组间：重一档（镜像|钉住）
│ ☐ 被钉上的单条             ×  │
└──────────────────────────┘
```

- **四套纸色自适应**：线色 = `color-mix(--sticky-ink 9%)`，每套纸色的 ink 都相对纸面高对比（≥8:1），9% 透明度在暖白/牛皮/淡青上呈浅灰细线、暗墨上呈浅亮细线——**一处定义，四纸免调**。
- **hover 反馈链**：删下划线后，整行淡底色（50% 灰 8%）继续承担「这行可交互」的反馈；标题 cursor:pointer 保留。符合 hover 反馈准则（不得无反馈，也不必下划线）。
- **WCAG**：分割线为纯装饰（信息由行边界与间距承载），非文本 3:1 条款不适用于装饰元素；不改可达性结论。

## 5. 可选加分项（拍板可选项，默认不做）

| 项 | 效果 | 建议 |
| --- | --- | --- |
| 完成态行分割线淡至 6% | 已完成行整体更「退后」 | 可与 ① 一起做，+1 行 CSS |
| 行 hover 底色从 8% 提到 10% | 反馈更明显 | 默认不做（8% 已够，避免吵） |

## 6. 验收标准

1. 相邻待办行之间有发丝线；首行上方、末行下方无线
2. 组间虚线明显重于行间线（层级：组 > 行）
3. 悬停待办文字无下划线；整行仍有淡底色反馈
4. 四套纸色逐一切换，分割线可见但不抢眼
5. 变更仅 `sticky.css`（预计 ±10 行），窗口/Rust/行为零改动
