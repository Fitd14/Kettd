# Kettd 产品路线图 v2（愿景驱动重排）

- 生成：2026-09-04 · 状态：规划中（不涉实现）· 取代：v2.1 战术排期（D1–D5）之上的战略层
- 愿景（北极星）：**桌面上的「个人知识·待办网」**——离线、可自定义、数据在你手里；待办与知识是一张互链的网，**桌面便签是你主动贴到手边的那一小撮**。

## 0. 战略重定（这次最大的变化）
- 产品内核从「待办 app + 可选便签」→「**待办 + 知识 双主体，便签是统一界面层**」。
- **知识库（KB）从"暂缓插件"转正为核心地基**。
- 不变的红线：离线、不出网、数据只在本机、反功能广度（不做平台/第三方组件、不做 Obsidian 式双链插件生态）。KB 定位是"**待办的上下文资料**"，不是"第二大脑工程"。

## 1. 分阶段路线图

### H0 · Now — 兑现 v2.1 承诺（~1–2 周）
目标：把"安静文具、记下来就安全"的信任坐实，别在追愿景时把已到手的口碑丢了。
- v2.1 收尾：毛玻璃真机验收（停实例重编）、`git push` 建回滚点、埋点前端尾巴（weekly_open + 设置页埋点开关/清空）、D5 定版删过期包。
- **便签 v2.1 版**（Rust+CSS，可并入 v2.1）：删三形态 → 单一现代便签；固定(置顶) / 拖拽记位 / 移出淡化 / 预设纸色。
- 出口：v2.1 正式发布。

### H1 · Next — React 地基 + 便签网雏形（~3–5 周）
目标：换到能承载愿景的前端基座，并验证"多张便签 + 钉"这个核心行为成不成立。
- **v3 迁移 M1–M5**（React + shadcn）：capture→底座→五视图（含已定稿的回顾/今天/收件箱/计划/设置 UI 重设计）→退役旧 src→a11y。
- **多张便签**：桌面可贴 N 张；先支持两类——`待办便签` + `自由便签`；便签的收纳/淡出/清理机制（防"贴满废纸"）。
- **KB 最小地基**（先不做双链）：笔记/片段 + 全文搜索（内存扫）。
- 🚦 **H1 验证门**：多张便签是否真被用？"钉"的动作有没有发生？——决定是否重投 KB。

### H2 · Later — 知识网成型（~1–2 月，压在 H1 验证之后）
目标：把 KB 转正为可见能力，兑现"知识网"愿景。
- **知识便签**：把 KB 里某段信息钉到桌面常驻。
- **任务 ↔ 知识 链接**：先**单向 link**（任务挂资料 / 便签引片段），验证后再评估**活引用**。
- KB 编辑/组织体验（Markdown、标签、搜索）成熟化。
- 🚦 **H2 命门假设**（必须先证）：*用户真会把资料钉到桌面常驻、而不是"壁纸化"视而不见吗？* 若否 → KB 停在"任务上下文资料"层，不追求"网"。

### H3 · Horizon — 探索（不承诺）
- 回顾页数据洞察（热力图/时间轴已有设计雏形）。
- "钉"的活引用 / 轻量双向、跨便签关系可视化。
- 可选：导入/导出到 Obsidian（当桥，不当核心）。

## 2. 排序逻辑（为什么这个顺序）
1. **先兑现 v2.1**：信任是资产，追新前先结承诺。
2. **再换地基（React）**：所有新 UI（便签网/知识）都要长在新栈上，先迁移避免在 vanilla 上做要扔的活。
3. **便签网雏形先验证行为**：多张+钉是低成本探针，先证"钉到桌面"是不是真需求。
4. **KB 重投压在验证之后**：最贵的错误是"自嗨建库"。H1 门过了才在 H2 认真做知识网。

## 3. 关键假设清单（每条标最便宜的验证）
| 假设 | 风险 | 最便宜验证 |
|---|---|---|
| 用户会把资料钉桌面常驻（非壁纸化） | Value | H1 自由便签先上，看"钉了还看不看/多久清" |
| 待办需要挂上下文资料 | Value | 先做任务单向 link，看使用率 |
| 多张便签比单张有用 | Usability/Value | H1 直接给多张，观察创建数 |
| React 迁移不拖垮 v2.x 迭代 | Feasibility/Viability | M1 capture 试点先跑通 |
| 单人离线工具能靠"工作台化"提粘性 | 商业/留存 | 埋点(已实现)看 4 周留存与功能触达 |

## 4. 对已产出物的影响
- 五视图 UI 设计增量（已定稿）→ 归入 **H1 的 M3** 落地。
- 便签规格 → 拆两半：**H0**（Rust+CSS 单张便签）+ **H1**（多张/多类型）。
- 知识库可行性/影响评估 → 从"暂缓"升级为 **H2 核心**，但投入时机仍受 H1 验证门约束。
- 回顾页热力图/时间轴 → H1 迁移时落地；数据洞察深化留 H3。

## 5. 一句话
**近期先兑现、中期换地基并验证"钉"的行为、远期才把知识网做实——用最小成本先证明愿景成立，再重投。**
