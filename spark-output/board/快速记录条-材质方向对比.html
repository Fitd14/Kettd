四条方向的实际代价

方向材质层数可读性与「桌面文具感」一致性工程风险改动量
A 实心纸片1（纸）最好 纸白实底，placeholder 对比度回到 4.86:1（卡片底口径）正中 —— 便签贴在桌上零 不依赖 OS 材质，Win10/11 一致删 acrylic 调用 + 改 3 行 CSS
C 92% 纸1（近实心）好基本一致，深色桌面上更不突兀低 仍保留 transparent 窗（圆角/阴影需要）改 2 行 CSS
B 单层玻璃1（OS 磨砂）差 浅色桌布上文字几乎化掉冲突 —— 系统控件语言，不是纸高 Win11 22H2+ acrylic 有黑屏/不刷新已知问题；apply_acrylic 在 Windows 不吃 tint，想调色只能退回 apply_blur改 CSS + 材质调用 + 阴影策略
D 现状2（磨砂+半透白卡）差两头不靠 —— 灰、脏、边界含混高 同 B，且叠加放大问题—
三个共性修复（选哪个方向都要做）：① 阴影空间从 margin:6px 提到 12–14px，否则 --shadow-md 的 14px 扩散必被窗口裁切 —— 这就是四角暗晕与最初"黑边"的同一个物理原因； ② 「+」按钮别用石墨实心 .btn（在浮条上是视觉黑洞），A/C 用 30×30 圆角方 + 纸白前景，B 用半透白底； ③ 保留 transparent:true 与 margin 的组合即可根治黑边，不需要 OS 磨砂 —— 透明窗解决的是"圆角外溢"，磨砂解决的才是"透出桌面"，而后者对一条只看 3 秒的输入框收益为零。
