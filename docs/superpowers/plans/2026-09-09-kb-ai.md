**Tech Stack:** Rust: `reqwest` + `rustls` (HTTPS client for embedding calls); `winapi` crate (DPAPI CryptProtectData — Windows-only, feature-gated). Frontend: no new deps (existing api.ts wrappers for the 3 new commands). `kb_index.json`: plain JSON (vector chunks; rebuildable on corruption).

**Spec:** `spark-output/design/kb-spec.md` §8 (AI config + secret security), §9 (hybrid retrieval pipeline), §11 (testing + parity 55→58)

**Global Constraints:**
- Commands: **55→58** (parity sync: generate_handler, test assert, V2-API §10)
- `kb_index.json` = derived data (rebuildable); read-corrupt → silent rebuild + fallback to local scan

use std::collections::HashMap;
use std::sync::Mutex;

/// Encrypted key-value store abstraction — platform-specific impl behind this trait.
pub trait SecretsKeeper: Send + Sync {
    fn save(&self, key: &str, value: &str) -> Result<(), String>;
    fn load(&self, key: &str) -> Option<String>;
    fn delete(&self, key: &str) -> Result<(), String>;
}

/// In-memory test double — no encryption, for unit tests.
pub struct InMemoryKeeper {
    store: Mutex<HashMap<String, String>>,
}

impl InMemoryKeeper {
    pub fn new() -> Self {
        Self { store: Mutex::new(HashMap::new()) }
    }
}

impl SecretsKeeper for InMemoryKeeper {
    fn save(&self, key: &str, value: &str) -> Result<(), String> {
        self.store.lock().unwrap().insert(key.to_string(), value.to_string());
        Ok(())
    }
    fn load(&self, key: &str) -> Option<String> {
        self.store.lock().unwrap().get(key).cloned()
    }
    fn delete(&self, key: &str) -> Result<(), String> {
        self.store.lock().unwrap().remove(key);
        Ok(())
    }
}
```

// ai/embedding.rs:
pub fn chunk_item(item: &KbItem) -> Vec<(u32, String)> {
    let mut chunks: Vec<(u32, String)> = Vec::new();
    // Chunk 0: title (high signal for embedding)
    if !item.title.trim().is_empty() {
        chunks.push((0, item.title.clone()));
    }
    // Chunk 1..n: split body_md by paragraphs (double newline), accumulate ~600 chars each
    let mut buffer = String::new();
    let mut chunk_id = chunks.len() as u32;
    for para in item.body_md.split("\n\n") {
        if buffer.len() + para.len() > 600 && !buffer.is_empty() {
            chunks.push((chunk_id, std::mem::take(&mut buffer)));
            chunk_id += 1;
        }
        if !buffer.is_empty() { buffer.push_str("\n\n"); }
        buffer.push_str(para);
    }
    if !buffer.trim().is_empty() {
        chunks.push((chunk_id, buffer));
    }
    chunks
}
```

fn cosine(a: &[f32], b: &[f32]) -> f64 {
    let dot: f64 = a.iter().zip(b.iter()).map(|(x, y)| (*x as f64) * (*y as f64)).sum();
    let mag_a: f64 = a.iter().map(|x| (*x as f64).powi(2)).sum::<f64>().sqrt();
    let mag_b: f64 = b.iter().map(|x| (*x as f64).powi(2)).sum::<f64>().sqrt();
    if mag_a == 0.0 || mag_b == 0.0 { 0.0 } else { dot / (mag_a * mag_b) }
}
