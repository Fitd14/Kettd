| 需求（理想态） | 实现现状 |
| --- | --- |
| 应用未运行时计划任务必达 | 仅托盘常驻方案，未运行不承诺 |

| AI 混合检索 | 已放弃摘除（2026-11-07），搜索纯本地 |
