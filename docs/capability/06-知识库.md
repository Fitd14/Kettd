# 06 · 知识库

## 设计

**容量**：≤5000 条。字段：标题 / 正文（Markdown）/ 标签 / 创建与更新时刻。

**编辑器**：Tiptap WYSIWYG 单一即时画布（编辑即渲染）；标题就地编辑（Enter 存 / Esc 还原）；正文防抖 800ms 自动写回。

**搜索**（纯本地，键入即渲染）：
- 打分：标题命中 +2、任一标签命中 +1、正文命中 +1；大小写不敏感
- 排序：分数降序，同分按更新时间倒序；空查询 = 全量按更新时间倒序
- 前端持全量条目，命中置前、其余补后

**标签**：入库归一（去空白/去空项/去重）；筛选为前端过滤，点同标签取消。

**条目动作**：
- 贴到桌面 → 创建知识便签
- 转为待办 → 预填标题、分类默认工作、自动挂载 kbRefs
- 删除 → 两步确认；被任务引用时提示「N 处引用将悬空」

**任务联动**：任务详情挂载资料（选择器整体替换 kbRefs）；条目删除后任务侧引用显示「📎 已失效」。

**Deep Link**：`#/kb?id={itemId}` 自动选中（支持页内 hashchange）。左清单可折叠，状态持久化。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 视图 | `views/KbView.tsx` + `components/kb/*` |
| 编辑器 | `rendering/tiptap-editor.tsx` + `renderer-registry` + `rendering/styles/prosemirror.css` |
| 样式 | `views/kb.css` |
| 后端 | `kb.rs`（CRUD + 打分）+ `commands.rs` kb 族命令 |
| 存储 | `notes.json`（与 `data.json` 物理隔离） |
| 测试 | `src-react/test/md-fidelity.test.mjs`（渲染保真） |

关键约束：
- ⚠️ AI 混合检索已于 2026-11-07 整体摘除（ai/ 模块删除、命令 59→55），**不要重新引入 AI 栈**；搜索保持纯本地
- 搜索打分只改 `kb.rs` 一处；前端 KbView 持全量数据重排
- 知识便签同步：`store-changed` 事件触发重拉；焦点在本窗时跳过防覆盖
- 删除条目后任务侧 kbRefs 悬空，前端展示「📎 已失效」而非静默丢弃
- 扩展动作（如新增「导出条目」）走 `commands.rs` 新增命令 + `api.ts` 封装 + `V2-API.md` 同步 + parity 门禁

- 已实现：WYSIWYG 编辑 / 标签 / 本地搜索 / 知识便签 / 任务挂载 / DeepLink / 5000 上限

- 历史：Phase 1–3 完整落地（渲染 → 便签联动 → AI 摘除），搜索退回纯本地
