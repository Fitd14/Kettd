# 05 · 待办悬浮窗

## 设计

- 镜像今天主列表（到期 + 顺延），勾选即完成，顺延项带「拖了 N 天」徽标
- 点标题打开主窗 /today
- Pin 置顶开关（默认开，落设置）
- ✕ = 只藏窗（显隐状态持久化），托盘勾选 / Alt+Shift+T 呼回
- 纸色/花纹跟随便签设置；空态提示 Alt+Shift+A

## 开发指南

| 层 | 入口 |
| --- | --- |
| 窗口 UI | `src-react/src/todo/TodoFloatWindow.tsx` + `todo.css`；入口 `todo.html` |
| 数据源 | `kernel/selectors.js` `todayList`（与今天视图同源） |
| 后端命令 | `hide_todo_float` / `register_todo_hotkey` |
| 托盘 | `runtime.rs` 勾选项 |
| 设置 | `settings.todoFloatPinned` / `todoFloatVisible` 持久化 |

关键约束：
- 数据源必须用 `todayList`，禁止另口径实现
- 窗口显隐状态落盘 `runtime.json`，重启按原样恢复
- 热键注册失败走统一回滚（见 08 设置）

## 现状

- 已实现：镜像 / 勾选 / Pin / 呼出隐藏 / 纸色跟随
- 边界：只读镜像（无编辑动作，行操作去主窗）
- 历史：原「待办便签」形态已废弃，迁移中丢弃 kind=todo，镜像功能由本窗承担
