# 02 · 快速记录

## 设计

**呼出**：全局热键 Alt+Shift+A（可改绑）或托盘「快速记录」。
**窗口**：宽 560，高度随内容动态伸缩（钳制 36–200px）；失焦自动收起并记忆位置；✎ 按住拖动。

**受限语法**（实时解析为 chips，点击 chip 从原文删除）：

| 类别 | 支持写法 |
| --- | --- |
| 分类 | `#工作` / `#学习` / `#生活` |
| 优先级 | `!高` / `!中` / `!低` |
| 日期 | 今天/明天/后天/本周X/下周X/星期X/周X（一二…日天或 1–7）/N月D日(号)/N.D/N/D |
| 时间 | 早上/上午/中午/下午/晚上 + N点[半\|整\|分]；H:MM（支持全角冒号） |

解析规则：
- 下午/晚上 <12 点 +12，中午 <11 点 +12；时 >23 或分 >59 丢弃时间 chip
- 只有时间无日期 → 今天该时刻
- **仅当截止带具体时刻才自动设提醒**（纯日期不提醒）
- 无任何 chip → 纯文本兜底进收件箱
- 缺省：分类=生活、优先级=中、source=capture；输入上限 200 字

交互：Enter 落库（空标题拦截）；Esc 关闭；回执「已记下 · 标题」+「加入今天?」，2s 自动收起（加入今天成功 900ms 收起）；保存失败保留输入「改完再按回车」。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 语法解析 | `src-react/src/kernel/capture.js`（纯函数，唯一实现） |
| 窗口 UI | `src-react/src/capture/CaptureWindow.tsx` + `capture.css`；入口 `capture.html` |
| 后端窗口 | `runtime.rs` 定位/动态高度；命令 `open/close_capture_overlay`、`capture_start_drag`、`capture_resize` |
| 落库 | `add_task`（source=capture），autoRemind 写 remindAt |
| 热键 | `register_capture_hotkey`；启动注册失败重试 4 次（400ms×n）+ 系统通知 |

关键约束：
- 扩展语法只改 capture.js，保持纯函数可测；chip 与原文子串一一对应（点击删除依赖 raw 匹配）
- 桥接惰性取 `__TAURI__`（注入可能晚于模块求值），不要缓存全局引用
- 高度上报走 `capture_resize`，后端钳制，前端不要自设窗口尺寸

## 现状

- 已实现：四类 chip 解析、纯文本兜底、回执态、加入今天、位置记忆、失焦收起
- 边界：无语音录入、无批量拆分、无英文长句 NLP；200 字上限；纯日期不自动提醒
