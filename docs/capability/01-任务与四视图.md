# 01 · 任务与四视图

## 设计

### 任务模型

| 字段 | 说明 |
| --- | --- |
| title / note | 标题 / 备注 |
| category | 固定三选：工作 / 学习 / 生活 |
| priority | high / med / low（高 / 中 / 低） |
| dueAt | 截止：`YYYY-MM-DDTHH:mm` 或仅日期 `YYYY-MM-DD` |
| remindAt | 任务提醒：`HH:MM`（每日循环）或完整时刻（一次性） |
| plannedDate | 计划日（仅日期）：「加入今天」写入此字段 |
| carriedFrom | 拖留天数（>0 显示「拖了 N 天」徽标） |
| done / doneAt | 完成态 / 完成时刻 |
| deletedAt | 软删时刻（回收站保留 30 天） |
| subtasks / notes | 子任务 / 多条备注 |
| kbRefs | 挂载的知识库条目 id（单向引用） |
| sortOrder | 手动排序位（未设按创建时间兜底） |
| source | capture / manual / seed |
| legacy | v1 迁移标记（完成无时刻，回顾页单列） |

时间全链路本地语义字符串，零 UTC 换算；带秒归零，带时区后缀只截断不换算。

### 今天（#/today）

成员判定（单一 selector，三处同源）：
- 逾期 = 未完成且 dueAt 日期 < 今天
- 今日 = 未完成、非逾期，且 plannedDate=今天 或 dueAt 落在今天
- 已完成不算今天待办，但算今天完成

三段式：逾期折叠条（「已逾期 N 项」）→ 顺延项 → 今日到期；主列表 = 到期+顺延，sortOrder 升序。

操作：内联输入回车建任务（plannedDate=今天）；逾期逐条「改到今天 18:00 前」（写入今天 18:00）/「移今天」/ 丢弃（软删+10s 撤销）；拖行/Alt+↑↓ 排序、j/k 导航、Enter 详情。

副标题：今天计划 N · 剩 N · 做完 N + 下一条提醒。空态：有完成 → 「今天清零 · 做完 N 件」庆祝；否则「今天还没有挑出来的事项」。

### 收件箱（#/inbox）

成员：未完成、无 plannedDate、无 dueAt、未删。按滞留天数三分组：今天进的（0）/ 本周（<5）/ 更早（≥5，琥珀警示）。

勾选出批量栏：加入今天 / 排期（选日期，写入当天 09:00，Esc 取消）/ 删除；右侧拖放区「拖到这里=加入今天」。空态提示 Alt+Shift+A。

### 计划（#/planned）

双 Tab（默认安排）：
- 安排：未完成且有 plannedDate/dueAt，按日分组升序，每行「→今天」
- 提醒：启停勾选、单次/循环徽标、hover 编辑时刻/稍后 10 分/删除；编辑日期留空=每天循环

### 回顾（#/review）

KPI：本周完成/连续打卡/本年总计/无日期完成。周期 Tabs：全年 52 周（默认）/近 90 天 13 周/本月 5 周。热力档位 0/1–2/3–5/6–9/10+，点格下钻当日清单。时间轴最近在前。streak 今天无完成从昨天起算。legacy 不进格子单列计数。周汇总可导出（见 07）。

### 侧栏角标

今天 = 到期+顺延（不含逾期、不含已完成）；收件箱 = 未计划无截止未完成数；0 不显示。

关键约束：
- **三处「今天」必须同一 selector**（侧栏角标/悬浮窗/统计卡），禁止第二份口径实现
- `update_task` 是部分字段 MERGE：未出现字段保持原值；时间字段自动归一，非法格式直接 Err
- 新增命令走四方同步（见 AGENTS.md），parity 门禁当场拦截不一致
- 改成员规则只改 selectors.js，并跑 `cargo test` + 真机核对三处计数
