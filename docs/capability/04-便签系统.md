# 04 · 便签系统

## 设计

**分池上限**（互不影响）：自由便签 ≤6 张；知识便签 ≤4 张。正文 ≤500 字。

**三态生命周期**：
- 展开：380×456 纸片，常驻置顶
- 缩小（mini）：380×40 悬浮条，显示正文首行（知识便签显 KB 标题）；点文本展开、⠿ 拖动；mini 态持久化，重启恢复
- 关闭（✕）：**即销毁**，数据窗口一并回收，无确认无撤销（误关靠写前备份兜底）

**外观**：
- 纸色四选：warm 暖白纸 / kraft 牛皮纸 / cyan 淡青 / ink 暗墨
- 花纹三选：无 / 墨竹 / 远山（后两者自动伴随朱砂「记」印）
- 移出淡化：鼠标离开淡至设定不透明度（默认 38%，范围 10–100%），移入恢复；mini 条不淡化

**自由便签**：失焦自动保存；Markdown 渲染开关（预览态点击切回编辑）。

**知识便签**（kbRef 指向知识库条目）：
- 知识库变更事件触发内容同步；焦点在本窗编辑器时跳过同步防覆盖
- 便签内编辑直接写回知识库条目
- 条目被删 → 显示「⚠️ 已失效（原资料已删除）」+ 拆除按钮
- 关闭时提示「数据保留在知识库」（与自由便签销毁语义不同）

**窗口管理**：新窗相对既有便签错位 +32px；建窗失败回滚已入库数据。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 窗口 UI | `src-react/src/sticky/StickyWindow.tsx` + `sticky.css` + `paper-patterns.tsx`；入口 `float.html` |
| 动态窗口 | `runtime.rs` 建窗（helper 线程 + 6s 超时 + 3s 存活探测） |
| 命令 | `create/list/update/delete_sticky` + `sticky_self` |
| 数据 | `store.rs` stickies 字段；`models.rs` 常量 `STICKY_CAP=6` / `STICKY_KB_CAP=4` |
| 知识便签 | `views/KbView.tsx` 贴桌面 → `createSticky({ kbRef })` |

关键约束：
- ⚠️ `create_sticky` 的 `kbRef` 必须是 invoke 顶层参数（嵌在 `args` 里 Tauri 匹配不到 → 恒 None）
- ⚠️ `content` 始终序列化（含空串）——曾因 `skip_serializing_if` 吞空串导致前端 `.split` 抛 TypeError 整树卸载黑屏
- ⚠️ 建窗命令必须 async（WebView2 同步建窗偶发无限挂起）
- close = `delete_sticky` 销毁，无撤销；mini 持久化重启恢复

## 现状

- 已实现：两池 / 三态 / 四纸色 / 三花纹 / 移出淡化 / 知识便签同步 / 失效提示
- 边界：自由便签 ≤500 字；close 无撤销（备份兜底）；待办镜像便签已废弃（迁移中丢弃）
- 已知陷阱：kbRef 顶层参数 / content 序列化 / async 建窗
