# 04 · 便签系统

## 设计

**可见合计上限**：自由便签与知识便签同池，`visible=true` 的便签合计 ≤5 张（隐藏不计入）；单张正文 ≤500 字。升级首启旧数据缺 `visible` 字段按 `true` 处理，已有 6 张旧便签不强制隐藏/关闭，只挡新建与重新打开。

**生命周期（关闭 = 隐藏，不再销毁）**：
- 展开：380×456 纸片，常驻置顶
- 缩小（mini）：380×40 悬浮条，显示正文首行（知识便签显 KB 标题）；点文本展开、⠿ 拖动；mini 态持久化，重启恢复
- 关闭（✕ / Alt+F4）：只置 `visible=false` 并藏窗，数据与窗口位置（`note_pos`）保留；在设置页清单可 `open_sticky` 重开（受可见合计 5 约束）；重启只恢复可见便签
- 显式删除（设置页两步确认 `delete_sticky`）：数据、窗口与位置记录一并回收，无确认无撤销（误删靠写前轮转备份兜底）

**外观**：
- 纸色四选：warm 暖白纸 / kraft 牛皮纸 / cyan 淡青 / ink 暗墨
- 花纹三选：无 / 墨竹 / 远山（后两者自动伴随朱砂「记」印）
- 移出淡化：鼠标离开淡至设定不透明度（默认 38%，范围 10–100%），移入恢复；mini 条不淡化

**自由便签**：失焦自动保存；Markdown 渲染开关（预览态点击切回编辑）。

**知识便签**（kbRef 指向知识库条目）：
- 知识库变更事件触发内容同步；焦点在本窗编辑器时跳过同步防覆盖
- 便签内编辑直接写回知识库条目
- 条目被删 → 显示「⚠️ 已失效（原资料已删除）」+ 拆除按钮
- 关闭 = 隐藏（正文始终在知识库）；删除便签不影响知识库条目

**窗口管理**：新窗相对既有便签错位 +32px；建窗失败回滚已入库数据（`open_sticky` 建窗失败回滚 `visible=false`）。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 窗口 UI | `src-react/src/sticky/StickyWindow.tsx` + `sticky.css` + `paper-patterns.tsx`；入口 `float.html` |
| 动态窗口 | `runtime.rs` 建窗（helper 线程 + 6s 超时 + 3s 存活探测）；`open_note_window` / `hide_note_window` 显隐不销毁 |
| 命令 | `create/list/update/delete_sticky` + `open_sticky` + `sticky_self` |
| 数据 | `store.rs` stickies 字段；`models.rs` 常量 `STICKY_CAP=5`（可见合计，含知识便签）；`visible` 字段旧数据缺省 true、true 时序列化省略 |
| 知识便签 | `views/KbView.tsx` 贴桌面 → `createSticky({ kbRef })` |

关键约束：
- ⚠️ `create_sticky` 的 `kbRef` 必须是 invoke 顶层参数（嵌在 `args` 里 Tauri 匹配不到 → 恒 None）
- ⚠️ `content` 始终序列化（含空串）——曾因 `skip_serializing_if` 吞空串导致前端 `.split` 抛 TypeError 整树卸载黑屏
- ⚠️ 建窗命令必须 async（WebView2 同步建窗偶发无限挂起）
- ⚠️ 关闭 = `update_sticky({ visible:false })` / 便签窗 Alt+F4（`CloseRequested` → `prevent_close` + 藏窗），**只隐藏不删数据**；mini 持久化重启恢复
- ⚠️ 上限唯一口径：`models::visible_sticky_count`（自由+知识同池，隐藏不计）；新建/重开统一文案「便签最多同时打开 5 张，请先关闭一张」
- ⚠️ `visible=true` 时字段被 serde 省略，前端判可见必须用 `visible !== false`（不能写 `!visible`）

## 现状

- 已实现：统一可见池（自由+知识）/ 四纸色 / 三花纹 / 移出淡化 / 知识便签同步 / 失效提示 / 关闭隐藏与重开 / 待办最小化持久化（待办悬浮窗侧）
- 边界：单张正文 ≤500 字；可见合计 ≤5；显式删除无撤销（备份兜底）；待办镜像便签已废弃（迁移中丢弃）
- 已知陷阱：kbRef 顶层参数 / content 序列化 / async 建窗 / visible 省略字段
