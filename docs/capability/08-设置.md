# 08 · 设置

## 设计

改动即存（增量补丁）。

| 设置 | 选项/范围 | 说明 |
| --- | --- | --- |
| 主题 | 纸白 / 暗色 | 即时跨窗同步并持久化 |
| 全局热键 ×4 | 任意组合键 | 快速记录/主窗口/新建便签/待办悬浮窗；四槽位互斥，换绑事务化（任一冲突整批回滚）；留空解绑（快速记录除外）；显示实际注册快照 |
| 便签纸色 | warm/kraft/cyan/ink | 全便签与悬浮窗共用 |
| 便签花纹 | 无/墨竹/远山 | 竹/山伴朱印 |
| 移出淡化 | 开关 + 10–100% | 默认开、38% |
| 免打扰 | 开关 + 起止 HH:MM | 默认 23:00–07:30 |
| 每小时提醒上限 | 3/5/10 | 超出排队不轰炸 |
| 本地度量 | 开关 + 清空 | 清空需 3s 内二次点击确认 |
| 数据与备份 | 健康状态/备份列表/恢复 | 打开数据文件夹入口 |

## 开发指南

| 层 | 入口 |
| --- | --- |
| 前端 | `views/SettingsView.tsx`（改动即存，增量 `set_settings`） |
| 后端校验 | `app/settings.rs`（范围校验 + 热键四槽事务） |
| 默认值 | `models.rs` `Settings::default` + `coerce` 兜底非法值 |
| 常量 | `commands.rs` `get_form_hints`（前端不硬编码分类/优先级/默认热键） |
| 热键注册 | `runtime.rs` 注册 + 失败回滚 |

关键约束：
- 新增设置项路径：`models.rs` 字段 + 默认 + coerce → `app/settings.rs` 校验 → `api.ts` Settings/Payload → `SettingsView.tsx` 控件 → `V2-API.md` §1 同步
- 热键换绑是事务：任一槽位注册失败 → 整批回滚字段并还原已换槽位 OS 绑定
- 校验范围：淡化透明度 10–100、remindCapPerHour 1–60、DND from/to 须 HH:MM
- 前端常量（分类/优先级/默认热键/上限）走 `get_form_hints`，禁止硬编码
