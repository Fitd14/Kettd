# 07 · 周汇总导出

## 设计

**入口**：托盘「本周汇总导出」/ 回顾页。

**周参数**：空/current/this/本周 → 本周；last/previous/上周 → 上周；`YYYY-Www` 指定周（ISO 周，周一~周日，周号 1–53）。

**Markdown 内容**：
- 四桶概览：完成 / 顺延 / 逾期 / 新建
- 分类分布
- 下周候选：拖留 ≥3 天 Top5（按拖留降序再优先级 high>med>low）
- 按日明细
- 完成明细
- 本地度量快照（四指标）

**CSV 内容**：BOM + 17 列全字段，导出**全部未软删任务**（不限本周）。

**目录**：入参 dir → 设置 exportDir → 数据目录/exports；同名文件自动追加 -2…-99 后缀，不覆盖。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 后端生成 | `export.rs`（周解析 / md / csv 模板） |
| 命令 | `commands.rs` `export_weekly` |
| 前端入口 | `views/ReviewView.tsx` 周汇总 details；托盘 weekly |
| 目录决策 | `export.rs` 内 `dir` → `settings.exportDir` → `data_dir()/exports` |
| 度量快照 | `commands.rs` 末尾追加 `telemetry::render_snapshot` |

关键约束：
- 周号走 ISO（`models.rs` `iso_week`），周一~周日；跨年周归到正确年份
- 改模板只改 `export.rs`；新增列同步改 CSV BOM 头与列数
- 文件名冲突自动 -N 后缀，不覆盖历史导出
- 度量快照追加在 md 末尾，新增指标需同步改 `telemetry.rs` 与 `render_snapshot`

## 现状

- 已实现：md 四桶+候选+明细+快照；csv 全量 17 列；目录决策；同名后缀
- 边界：csv 不限本周（全量未删）；无自动周五草稿（PRD 理想态未实现）；无图片版周报
- 历史：Phase 3 落地，首版不做 AI 润色（明文聚合即竞争力）
