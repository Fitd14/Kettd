# 03 · 提醒与通知

## 设计

**两个来源**：独立提醒（计划页管理）+ 任务 remindAt。

**格式与重复**：
- `HH:MM` 单时刻 / `HH:MM/HH:MM` 多时刻（每个时刻各触发一条）
- 重复规则：none 单次 / daily 每天 / workdays 周一~五 / weekly 与上次触发同星期
- 含 `T` 的完整时刻 = 单次：独立提醒触发后置 completed 并停用；任务提醒触发后清空 remindAt
- 任务 `HH:MM` 提醒 = 每日循环，不清除；已完成/回收站任务不触发

**调度**：1 秒 tick；系统通知 title 固定「待办提醒」，body = `标题 · YYYY-MM-DDTHH:mm`，稍后追加「（稍后提醒）」。

**免打扰**：默认 23:00–07:30（可关、可改、支持跨零点，区间左闭右开）；期间静默入账，出窗合并一条「免打扰期间有 N 条提醒」。

**每小时上限**：默认 3 条（设置可选 3/5/10，校验范围 1–60）；1 小时滑窗预扣预算，超额留队列下轮再试，宁少不超。

**错过补发**：启动时把已到点项合并一条「错过 N 条提醒」；错过超 24 小时只记账不发通知。

**稍后提醒**：1–720 分钟，目标 = 现在 + N 分钟。

**去重**：fired 稳定键 FIFO，上限 400 条；通知发送失败也记 fired 不重发。

**承诺边界**：提醒依赖应用运行（托盘常驻）；完全未运行不承诺到点必达，下次启动补发。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 调度 | `src-tauri/src/scheduler.rs`（1s tick，四段锁协议：决策→通知→落库→emit） |
| 提醒业务 | `app/reminders.rs`（snooze/toggle/delete 命令） |
| 校验 | `models.rs` 时间格式、设置上限范围 |
| 通知出口 | `ports/notifier.rs` → `infra/tauri_notifier.rs`（可换测试替身） |
| fired 持久 | `store.rs` 键 `r\|id\|stamp` / `t\|id\|stamp`，FIFO 400 |
| 前端 | `views/PlannedView.tsx` 提醒 Tab；`views/SettingsView.tsx` DND 与上限 |

关键约束：
- 新增提醒类型需同步：models 校验 + scheduler 收集 + app/reminders 命令 + 前端 PlannedView 行
- 锁纪律：网络/通知调用**必须在锁外**，避免阻塞主线程
- 测试：`cargo test` 覆盖时间契约与调度规则；通知行为需真机验证

## 现状

- 已实现：4 种重复 / 多时刻 / 免打扰 / 上限 / 稍后 / 错过补发 / fired 去重
- 边界：托盘常驻前提；错过 >24h 只记账；通知失败不重发
- 未实现：PRD 理想态的「应用未运行时计划任务必达」（当前仅托盘常驻方案）
