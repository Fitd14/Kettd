# 10 · 本地度量

## 设计

仅本机 `events.jsonl`，绝不出网；可关闭、可清空。

**四个指标**：
1. **捕获时延 P50**：快速记录落库耗时中位数（偶数取均值）
2. **本周快录数**：本 ISO 周 `capture_commit` 条数（目标 ≥25/周）
3. **提醒触达率**：shown / (shown + 运行中 missed)；应用未运行错过的不入分母
4. **周汇总采用**：本周是否打开/导出过周汇总

**事件文件**：`%APPDATA%\todo-list\events.jsonl`；>1MB 自动轮转归档为 `events.{unix秒}.jsonl`；mpsc 容量 512、批写 ≤64、满即丢。

## 开发指南

| 层 | 入口 |
| --- | --- |
| 落盘 | `telemetry.rs` `record_str` 入口；mpsc 异步批写 |
| 前端埋点 | `api.ts` `trackEvent(name, props)` |
| 设置 | `SettingsView.tsx` 开关 + 清空（3s 二次确认） |
| 指标聚合 | `telemetry.rs` `render_snapshot`（读尾 8000 行） |

关键约束：
- 新增事件：命名 snake_case；字段 `name` + `props`（JSON 字符串）；绝不出网
- 新增指标：改 `render_snapshot` + 设置页展示；保持四指标口径稳定
- 队列满即丢，不阻塞业务；批写 ≤64 条/次
- 文件轮转 >1MB，不自动删除旧归档（用户手动清理）
