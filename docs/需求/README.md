# 需求文档

分层结构：

| 层 | 文件 | 内容 |
| --- | --- | --- |
| 总体需求 | [总体需求.md](总体需求.md) | 产品定位、用户画像、目标与度量、价值主张、约束与红线、发布策略 |
| 功能需求 | [功能需求/](功能需求/) | 按功能模块拆分的需求规格与验收标准 |

- 想了解"某功能应该做什么" → 功能需求/ 对应模块
- 想了解"某功能实际怎么做的" → 功能文档/ 对应模块
- 想了解"系统怎么搭的" → [ARCHITECTURE.md](../ARCHITECTURE.md)
- 想了解"命令接口契约" → [V2-API.md](../V2-API.md)
