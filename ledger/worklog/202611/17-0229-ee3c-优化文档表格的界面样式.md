## Background

用户原话（2026-11-17）：「优化文档 表格的ui样式，目前列边界线不清晰，title 颜色太亮 操作按钮需要分两块 一个是表格估计操作按钮 一个是列行固定操作按钮」

现状核查：
- 边线：`src-react/src/rendering/styles/prosemirror.css:225-228` 的 `th/td` 用 `border: 1px solid var(--line-warm, hsl(var(--muted-foreground) / .25))`，前景色 25% 透明度在纸白底上几乎看不见；同文件 `:206-221` 还有一组被覆盖的旧表格规则（margin 0.5em、padding .4em .8em）。
- 表头：`prosemirror.css:218-221` 的 `th { background: var(--seal-soft, hsl(var(--seal) / 0.12)) }`，暖红 12% 铺满整行，是「太亮」的来源；正文用 `--ink-1`，表头文字未单独压暗。
- 操作栏：`src-react/src/rendering/tiptap-editor.tsx:1339-1363` 只有一块表格气泡，`+行/−行 · +列/−列 · 删表` 混排；表头行禁删（`flags.tableHeader` → disabled）。
- 表格不可拖列宽：`tiptap-editor.tsx:637` 为 `TableWithAlignment.configure({ resizable: false })`，全仓无 `colwidth`，所以「固定列宽」这类操作目前没有底座。

## To Do

- 真机核对：表头对比度、长表格横向滚动时表头表现、窄窗下两段工具栏是否折行。

**第一轮真机回归（2026-11-17，三条，均未修）**

- **R1 两把手在右上角重叠、挡掉单元格操作**：顶行末列时 `c.right ≈ t.right`、`c.top ≈ t.top`，代入位置公式后表级把手占 `x[-22,-4] y[-12,+6]`、单元格把手占 `x[-20,-2] y[+2,+20]`（18×18），垂直只差 14px → 重叠 16×4px。更致命的是表级面板 `top: calc(100% + 4px)` 从 `T+10` 起、高 28px，正好盖住单元格把手下半段（`T+10..T+20`）与单元格面板上半段（`T+24..T+38`）；而面板是 `:hover` 就展开（`prosemirror.css:301`），搭桥 `::after` 又把 hover 区往下延 10px（`:253-260`），于是「经过」即弹面板、点击落在表级面板上。两个 `.kb-tbl-tools` 同级无 `z-index`，靠 DOM 顺序绘制（单元格面板压表级面板，但表级面板压单元格把手）。
- **R2 把手像「白色 icon」，点了没反馈、看不懂作用**：`.kb-tbl-handle` 是 18×18 的浅色 chip（`prosemirror.css:263-279`，`background: hsl(var(--secondary))`、默认 `opacity:.5`），配 11–12px 图标；面板本来就靠 hover 开着，点击只是把 `open` 从 `null` 切到 `'table'`，视觉上没有任何变化 → 用户感知「点了没反应」。两枚把手图标语义也不一致（表级 `TableIcon`、单元格级 `MoreHorizontal`）。
- **R3 行/列调整仍是数字 stepper**：表级面板里是 `行 − 5 +`、`列 − 3 +`（`.kb-tbl-axis` + `.kb-tbl-num`，`prosemirror.css:312-328`），用户要求改成图形方式，参照工具栏表格钮的网格选择器。

## Next

R1/R2/R3 的修法待用户拍板，候选（按改动面从小到大）：

1. 面板改成**只在点击后开**（`prosemirror.css:301` 去掉 hover 那条，hover 只负责把手 `opacity`）——一次消掉 R2 的「点没反馈」和 R1 的「经过即弹」；再给把手加 `aria-pressed` 与开态底色，点击有可见变化。
2. **位置解耦**：表级把手抬到表格外框上方（`top -= 22`）或挪到表格左上角，右上角只留单元格把手。
3. **碰撞让位**：`measure` 里比较两矩形，相交时表级优先让位（`top -= 22` / `left -= 24`），优先级写成「单元格 > 表格」。
4. R3：把 `行 − n +` 换成网格点选（可复用 `.kb-grid-picker` 的 18px 网格 + hover 高亮，尺寸取 `max(当前, 4)+1`，点 N×M 表示「目标行列数」），或退一步用纯图标增量（去掉 `.kb-tbl-num`）。
5. 两个面板显式分层 `z-index`，不依赖 DOM 顺序。

落地入口：`src-react/src/rendering/tiptap-editor.tsx` 的 `EditorTableTools`（`:248-491`）、`src-react/src/rendering/styles/prosemirror.css` 的 `.kb-tbl-*` 段（`:239-328`）。
